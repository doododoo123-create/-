# v0.19.0 검증 결과

검증일: 2026-10-23. 일반판과 모바일 경량판은 같은 엔진23·세계·규칙·저장 형식이다. 이번 변경은 UI 전용이며 src/engine, src/model, src/storage는 수정하지 않았다.

## 자동 검사

- `npm test`:238개 통과, 실패0. 신규 `campaign-v19.test.js`9개 포함.
- `npm run check`:130개 JavaScript 파일 구문 검사 통과.
- 실제160영토8차례의 모든 장면과 결과 반영 단계를 순회했다. 소유국이 그대로인 점령 빗금은 요약·다음 국가·생산에서 사라지지 않으며 다음 계절 첫 팝업에서만 비어진다.
- 기존 끊김은 summary 장면의 event.index 누락으로 현재 차례의 공개 범위를−1로 계산해 발생했다. summary를 해당 차례의 전체 공개로 처리하고 조기 round_end 정리를 제거했다.
- 재점령은 마지막 공개 소유국으로 빗금을 교체하고 계절 시작 바탕색을 유지한다. transient frames가 없는 저장 기록도 같은 빗금/전투 흔적/전선을 복원한다.
- 빗살은 이번 계절 공개된 전투·점령 지역의 현재 적대 공유 경계만 사용한다. 모든 빗살의 시작/끝이 자국 다각형 안에 있으며 아군/무주지/해안/물리 경계 없는 연결은 제외한다. id가 없는 격자 셀의 공유 경계 캐시도 구분한다.
- 좌/우/수직 공격 모두 전투 카드의 좌우 순서만 선택한다. 지도 카드 화면 너비가 이전 배율별 정확히1.2배인지 확인했다.
- 승상 임시 카드는 선택/실행/증가량 판정·반영에만 나타나며 해당 인물의 초상을 사용한다. 병력/주둔지/인물을 실제 세계에 추가하지 않고 제목에 null 병력을 표시하지 않는다.
- 카드별 병력 변화와 강화 수치는 기록된 전후 차이와 일치하고 큰 외부 변화 상자를 생성하지 않는다. 승패는 카드 중앙, 각자 손실은 카드 위에 있으며 주사위 확정 전에 결과를 표시하지 않는다.
- 기존 원본 v11 대조·D30 손실/점령/이동·해상 보급·계절·왕/승상·전사/후임·저장·과거 재생·불변성 검사를 유지했다.

## 브라우저 검사

`python tests/studio_v19_smoke.py`는 두 단일 HTML을 Chromium에서 실행한다.1600×1000 일반판,900×600 모바일 경량판,390×844 및844×390을 검사한다.

- 50%와500%에서 지도 카드 화면 너비28.8px/96px, 핀 끝의 정확한 영토 이름 앵커, 확대에 따른 크기 증가.
- 전투 카드가 같은 높이의 좌우에 놓이고 실제 영토 기준점에 따라 순서만 변경. 모든 보정10개와336px 전투창 유지, 카드/역할/손실과의 겹침 검사.
- 전투 외 카드와 카드 부모 opacity1. 지역명 축소, 카드 이름 대비 작은 흰색 변화 글자, 카드 가운데 결과/회색 처리/카드 위 실제 손실.
- 왕 옆 임시 승상 카드와 그 위 선택/주사위 창, 왕/승상 선택창의200px 너비·화면 내 배치, 별도 중복 인물 사진 없음.
- 실제 역사8배속 연속 재생:41차례 요약과42차례 시작의 점령 빗금이 같고,42차례 생산 중에도 유지,43차례 계절 팝업에서 빗금/전선/전투 흔적/화살표 정리.43차례 종료 소유권은 엔진 기록과 일치하고 실제 현재 저장은 바뀌지 않는다.
- 계절 팝업 정지/배속, 수동 카메라 유지, 국가색 실선 후퇴와 채운 화살촉, 이전 화살표86%, 새 경기 준비와 계절 팝업 중 턴 건너뛰기.
- HTTP로 받은 단일 HTML 오프라인 재실행과 외부 자원 요청/JavaScript 예외 검사.

화면은 docs/v19-normal/mobile-season,royal,minister,minister-die,feedback,battle,result,retreat,summary.png에 보관한다. 좁은 화면은 .artifacts/v19-mobile-390.png와 v19-mobile-844.png다.

## 배포와 한계

`npm run release`로 두 루트 HTML과 dist 실행본을 함께 갱신한다. 두 파일의 외부 이미지·CDN·서비스 의존성은 없다. 기존 경기는 새 실행 없이 새 화면으로 이어진다. 이전 엔진22 이하의 후퇴 규칙을 자동 변경하지 않는다.

클라우드 Chromium 정책은 file://를 차단하므로 실제 Windows 더블클릭과 물리 Android/iPhone 동작·성능 측정은 이번 검증 범위 밖이다. 브라우저에서 화면 크기와 오프라인 실행을 검사한 결과와 실기기 검증을 구분한다.
