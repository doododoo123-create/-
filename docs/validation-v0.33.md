# v0.33.0 검증

검증일: 2026-10-27 (한국 시간). v0.32.0을 기반으로 관전 UI와 재생 순서만 변경했습니다. 엔진29·세계/진행/역사 파일 형식과 전투 규칙은 유지합니다.

- `npm test`: **443개 통과, 실패0**. 기존 전투·저장·역사·난수·사운드 검사에 v0.33 공개 시점/지도 장면 보존/최근 사건/전사D10 검사8개를 추가했습니다.
- `npm run check`: JavaScript **229개 파일 구문 검사 통과**.
- `python tests/studio_v33_smoke.py`: 실제 배포 HTML을 Chromium에서 인터넷 없이 실행했습니다. 일반판1600×1000, 모바일판844×650과390×844 모두 통과했습니다.
- 실제 화면에서 공격 눈금→수비 합산→승패 공개→기존 공격/수비 이동→후퇴/점령 전선→다음 대결을 확인했습니다. 판정 중 카드 이동·화살표·점령이 먼저 나타나지 않는지, 이동 중 정지/재개와 대결표 펼치기가 동작하는지 검사했습니다.
- 공세 요약의 중복 없는 참가자, 세 전투 목록, 최근 사건4개의 시간순 표시를 검사했습니다. 사건 클릭으로 정지·영토 이동·강조하고, 저장된 현재 경기와 역사 내용은 그대로인지 확인했습니다. 좁은 화면의 최근 사건과 조작 버튼 겹침도 검사했습니다.
- `STUDIO_TEST_LABEL=v33 python tests/studio_v29_smoke.py`: 일반판/모바일판 모두 내장 글꼴·라이선스,5MiB 초과 세계 가져오기/취소,전체 역사 가져오기·재생·내보내기,이전27역사 이어하기,공유/전체 화살표,작은 혼란 표시,손상 파일 거부와 재실행 복원 검사를 통과했습니다.
- 브라우저 검사 전체에서 앱 예외와 외부 요청 실패 **0건**이었습니다. 일반판/모바일판 HTML에는 그림·글꼴·효과음·실행 코드가 포함됩니다.

화면 기록은 `docs/v33-*-dice.png`, `*-movement.png`, `*-summary.png`, `*-events.png`입니다. 작은 테스트 세계로 다중 전투·이동·점령을 재현했으며, 기본160영토 시작 화면도 확인했습니다.

검증 환경은 Linux Chromium과 휴대전화 크기의 브라우저 화면입니다. 실제 휴대전화 성능, Windows/Safari 실기,물리 스피커 청취를 검증한 것은 아닙니다. 클라우드 정책상 `file://` 접근이 차단되어,동일한 완성 HTML을 로컬 HTTP 응답으로 전달하고 오프라인 상태로 실행했습니다.
