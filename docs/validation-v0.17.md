## 이전 버전 호환

Git 태그 v0.16.0의 실제 소스를 `/tmp/saguk-v16-baseline`에 별도로 읽어18턴 실행한 엔진21 저장을 새 엔진으로 복원했다. battlefieldRecovery 누락값이 false이며, 복원 직후 상태와 과거1/8/18턴의 전투·이동이 원본과 일치했다. 이후7턴을 각각 진행해 난수와 전체 엔진 상태가 계속 일치했다. 새 실행도 저장/복원/역사 재생 시 이동 사건이 일치한다.

## 브라우저

`tests/studio_v17_smoke.py`는 실제 빌드한 일반/모바일 단일 HTML을 Chromium에서 연다.160영토 표시,50/500% 카드 크기와 핀 위치, 전체 보정/미판정 점수 비공개, 전투 창·지도 카드 배치, 점령자 실제 위치, 한 바퀴 효과 정리,42턴까지8배속 역사 연속 재생, 현재 저장 보존, 새 엔진22 실행과 수도 예비병 상한, HTTP에서 받은 HTML의 오프라인 동작을 확인한다.

추가로 모든 공세 화살표가 실제 인접 영토 사이인지, 기본336px 판정창과43.2px 다이스인지, 장군 선택으로 일반 행군 경로를 표시/숨길 수 있는지, 이동 점이 경로 위에서 움직이고 정지 상태를 따르는지 확인했다. 실제 브라우저 JavaScript 예외와 요청 실패는 일반/모바일 모두0이다.

## 배포와 한계

`npm run release`로 루트와 dist의 두 HTML을 생성했다. 각각 파일 내용이 일치하며 외부 이미지·CDN·계정이 필요 없다. 클라우드 Chromium 관리 정책에서 file:// 열기가 ERR_BLOCKED_BY_ADMINISTRATOR로 차단되므로 파일을 직접 여는 동작은 확인하지 못했다. HTTP 단일 HTML을 오프라인으로 다시 여는 동작은 검증했다. 실제 Windows/Android/iPhone 기기와 성능 수치는 별도 확인이 필요하다.
