# 사국쟁패 Studio v0.32.0 업데이트

배포일: 2026년 10월 27일

여러 장수가 같은 전선에서 반복해서 싸울 때 관전 시간이 길어지는 문제를 줄였습니다. 개별 전투는 기존 규칙으로 계산하고, 화면에서는 집단군·연속 공세를 빠르게 처리한 뒤 결과를 요약합니다.

다운로드한 HTML을 바로 열어 플레이할 수 있습니다. 업데이트 도구, 기존 실행 파일 선택, 패치 적용, Node 설치는 필요하지 않습니다. 링크가 코드로 열리면 다른 이름으로 링크 저장 후 여세요.

## 1. 집단군 전투 빠른 처리와 공세 요약

- 같은 국가 차례에 같은 상대와 인접한 전장에서 이어지는 전투를 하나의 공세로 묶어 재생합니다. 떨어진 전선은 별도로 처리하고, 단독 전투는 기존 재생을 사용합니다.
- 화면은 **접근 → 빠른 전투 처리 → 공세 결과 요약** 순서로 진행합니다.
- 묶인 전투에서는 개별 주사위 회전·보정 합산·반복 대기를 줄이고, 처리한 전투의 결과와 지도 변화를 빠르게 보여줍니다.
- 요약에는 대표 장수, 중복 없이 집계한 양측 참전 장수, 실제 대결의 승·패·무, 양측 병력 손실, 영토 획득·상실·순증을 표시합니다. 무방비 진입은 실제 주사위 대결과 구분합니다.
- 전사·수도 함락·국가 멸망이 있으면 요약에 함께 표시합니다. 아직 처리하지 않은 전투 결과는 미리 표시하지 않습니다.
- 요약은 자동으로 넘어갑니다. 요약창을 눌러 멈추거나 **상세 보기**에서 원래 개별 전투를 확인할 수 있고, **계속 ▶**으로 진행할 수 있습니다.
- 상세 보기는 이미 기록된 장면을 다시 보여줍니다. 주사위를 새로 굴리거나 현재 경기·저장·역사를 변경하지 않습니다.

## 2. 16배속 추가

- 진행 속도를 **0.5 / 1 / 2 / 4 / 8 / 16배속**으로 선택할 수 있습니다.
- 일반 시뮬레이션의 배속 선택과 지도 전체화면의 **+ / −** 단축키에서 16배속을 지원합니다.
- 일시정지·재개와 과거 역사 재생에서도 같은 배속을 사용할 수 있습니다.

## 3. 4·8·16배속 효과음 개선

- 8배속 이상에서 대부분의 일반 효과음을 생략하던 처리를 바꿨습니다.
- 고배속에서는 긴 이동음·반복 굴림음·보정음은 간소화하면서, 선택 확정·전투 결과·점령 등 핵심 효과음을 남깁니다.
- 집단군 빠른 전투와 최종 요약에도 효과음을 연결했습니다.
- 다음 국가 차례로 넘어갈 때 짧은 결과음의 끝부분이 바로 잘리지 않도록 했습니다.
- 일시정지·음소거·역사 전환 때는 재생 중이거나 준비 중인 소리를 취소합니다. 전체 음량과 기존 종류별 소리 설정을 따릅니다.

## 4. 왕의 첫 행동 선택만 1배속으로 보기

**관전 설정 → 국왕의 첫 행동 선택은 항상 1배속**에서 켜고 끌 수 있습니다. 기본값은 **켜짐**입니다.

| 장면 | 옵션을 켰을 때 |
|---|---|
| 왕이 전쟁·내정을 정하는 첫 행동 선택 | 항상 1배속 |
| 공격 상대국 선택 | 사용자가 선택한 배속 |
| 승상의 선택과 내정 판정 | 사용자가 선택한 배속 |
| 장수 전투·이동·집단군 공세 요약 | 사용자가 선택한 배속 |

예를 들어 16배속을 선택해도 왕의 첫 행동 선택은 1배속으로 보고, 그 뒤에는 16배속으로 이어집니다. 옵션을 끄면 왕의 첫 선택도 선택한 배속으로 진행합니다.

## 5. 관전 설정

시뮬레이션과 지도 전체화면에서 **관전 설정**을 열 수 있습니다.

| 옵션 | 기본값 | 적용 |
|---|---|---|
| 집단군 전투 빠른 처리 | 켜짐 | 다음 국가 차례부터 장면을 묶어 재생 |
| 국왕의 첫 행동 선택은 항상 1배속 | 켜짐 | 왕의 첫 행동 선택 재생에 적용 |

두 관전 옵션은 이 브라우저에 저장하며, 세계 규칙·진행 저장과 따로 관리합니다. 관전 방식 변경을 위해 새 경기를 시작할 필요는 없습니다.

## 6. 전투 밸런스와 기록

이번 변경은 관전·재생 기능입니다. 전투 계산은 기존 엔진29를 유지합니다.

- D30, 병력 우세·능력·전적·지형 보정과 기존 난수 순서를 유지합니다.
- 이동·출전·피로·손실·점령·정비·혼란·전사·왕의 방어 규칙을 유지합니다.
- 장수별 승수·역전승 별·성장은 기존 실제 전투 결과에 따라 기록합니다.
- 여러 장수를 하나의 새 주사위로 대결시키거나, 합산 병력으로 기존 병력 보정을 다시 계산하지 않습니다.
- 점령은 기존 개별 공세의 결과를 모아 표시합니다. 집단군 전체를 최대 3칸으로 새롭게 제한하거나, 한 번의 승리에 장수 수만큼 추가 점령권을 지급하지 않습니다.
- 같은 영토를 여러 번 주고받아도 요약의 영토 순증은 공세 시작과 종료의 실제 소유권을 비교합니다.

## 7. 바로 실행하는 일반판·모바일 경량판

- 두 HTML 모두 코드·그림·글꼴·효과음을 자체 포함합니다. 파일을 열면 자동으로 게임을 준비합니다.
- 최신 Chrome·Edge·Safari에서 실행하세요. 인터넷·계정·외부 CDN·별도 설치가 필요하지 않습니다.
- 일반판과 모바일 경량판의 규칙·세계·진행 저장 형식은 같습니다.
- 내장 OFL Noto 계열 글꼴을 한국어 표시에 맞게 재생성하고, 현대 한글 11,172자와 선택된 한자·라틴·일본어·기호 매핑 및 라이선스·해시를 확인했습니다.
- 세계·역사 파일 불러오기는 기존 기능을 이용할 수 있습니다. HTML 파일 주소나 브라우저가 바뀌면 자동 저장 공간이 달라질 수 있습니다.
