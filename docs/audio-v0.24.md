# v0.24 효과음 적용과 조작

고전 전략 효과음팩 v2의42개 MP3를 원본 그대로 내장한다. OGG는 같은 음원의 다른 형식이라 중복하지 않는다. BGM이나 지속 환경음은 이번 범위에 포함하지 않는다. 동봉 라이선스는 상업적 게임·영상 사용과 수정/재배포를 허용한다고 기재한다. 원문은 assets/sounds/classic-v2/LICENSE.txt에 보관한다.

## 사용법

상단 소리/지도 전체화면 스피커 → 소리 설정. M은 입력 중이 아닐 때 음소거를 전환한다. 설정창은 경기를 멈추며 닫아도 자동으로 재개하지 않는다. 전체50% 기본, 조작/주사위/이동/전투·내정/중요 사건별 음량을 따로 조절한다. 녹화용은 조작음을 끈다. 조용히 듣기는 전반적으로 낮춘다. 브라우저가 첫 클릭 전에 오디오를 막는 것은 정상이다. 지원하지 않으면 게임을 계속 실행하고 설정창에서 안내한다.

효과음42종 미리듣기는 원본 음원을 들려준다. 미리듣기는 종류별/녹화용 설정의 영향을 받지 않고 전체 음량/효과음 켜기를 따른다. 버튼을 바꾸면 이전 미리듣기를 멈춘다. 실제 경기는 해당 장면 길이에 맞춰 짧게 재생할 수 있다.

## 장면 연결

| 보이는 장면 | 적용 |
|---|---|
| 버튼·탭·창·지도 선택 | 목패 클릭,확정,취소,두루마리 펼침/접기,지도 말 놓기. 연속 지도 이동/확대는 소리를 반복하지 않음 |
| 국왕 행동/상대국·승상 정책 파칭코 | 목패 클릭 최대4회→확정. 후보1개는 회전음 생략 |
| 주사위 회전 | 기본0.9초 구간은0.65초 한 알 음원. 느린 장면은1.12초 나무판,극히 짧은 장면은 짧은 충돌 |
| 주사위 음색 선택 | 나무판/천/컵/충돌/번갈아 듣기. 긴 음원은 끝부분의 짧은 구간을 사용해 연출 시간을 늘리지 않음 |
| 눈금 공개·보정·확정 | 착지→0이 아닌 실제 보정마다 가산/감산→최종 점수. 긴 굴림음에 포함된 착지는 중복하지 않음 |
| 숨긴 출정 판정 | 무음. 거부 결과가 지휘관 위에 보일 때만 내정 실패·출정 거부음 |
| 실제 행군 | 갑옷 행군. 제자리 수비·경로 없는 재배치·전투 대형만 변경하는 동작은 생략 |
| 공격 접근·전열 형성 | 칼 휘두름→전열 충돌,후속 수비대/역공격은 쇠붙이 충돌 |
| 전투 결과 | 중립: 대승/압승은 승전,작은 승리는 충돌,무승부는 교착. 관심국 선택: 그 국가의 승전/패전. 수비 승리는 패전으로 취급하지 않음 |
| 점령 빗금 시작 | 깃발 꽂기. 한 점령 장면의2~3영토에 중복하지 않음. 무전투 점령에 가짜 승전음을 붙이지 않음 |
| 내정 결과 | 실제 모병 증가→모병,충원량 증가→장부,지휘한도 증가→보급,그 외 성공→내정 승인. 실패는 실패음 |
| 실제 충원·계절 생산 | 실제 양수 증가만 보급/장부음. 장군별로 반복하지 않고 묶음당1회. 자동 저장은 무음 |
| 계절 공지 | 봄/여름/가을/겨울 각각 해당 음원 |
| 수도 함락·국가 멸망 | 성문 함락/국가 멸망. 같은 사건의 초점/반영에서 중복하지 않음 |
| 전사·임관 | 실제 사망 반영/새 장군 또는 후임 활성화 때 전사/임명. 전사 판정 눈금 전에 결과를 누설하지 않음 |
| 세계 저장 | 사용자가 세계 저장을 눌러 성공할 때 장부 저장 |
| 통일 | 실제 정복 종료 때 천하통일 군례. 유한 턴 제한 결산·건너뛰기는 통일로 취급하지 않음 |

차례 시작음은 기본 끄기다. 켜면 국왕 선택 시작에만 한 번 사용하며 계절 공지와 겹치면 생략한다. 음색 번갈아 선택은 장면 식별자로 정하며 게임 난수를 쓰지 않는다. 기본 설정에서 모든42종을 경기마다 강제로 재생하지 않는다. 대체 음색과 관심국 패전 등은 해당 선택/상황에 사용한다.

## 정지·배속·기록

- 정지/음소거/화면 숨김/장면 변경은 예약 소리와 늦은 해독 결과를 취소한다. 굴림/행군의 남은 부분만 재개한다. 확정/승패 같은 일회성 소리는 재개나 지도 재렌더로 반복하지 않는다.
- 고배속 간소화:4배 이상은 이동·반복 클릭/보정음을 생략하고 확정·결과를 짧게,8배 이상은 계절·수도 함락·전사·멸망·통일만 유지한다. 간소화는 끌 수 있다. 음원 재생 속도를 높여 음색을 변형하지 않는다.
- 역사 행을 새로 열면 해당 방문의 장면을 따라 재생한다. 현재 경기로 돌아와도 현 경기의 중복 방지 상태는 보존한다. 건너뛰기가 미공개 전사/멸망/통일음을 한꺼번에 재생하지 않는다.
- 중요 사건 중 다른 종류를 낮추며 통일>멸망>전사>수도>계절 순으로 우선한다. 논리 동시 재생4개,해독 버퍼8MiB LRU. 클릭 뒤 자주 쓰는 짧은8종만 먼저 준비하고 나머지는 필요할 때 해독한다.
