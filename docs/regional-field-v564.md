# v0.56.4 간격 압축 전술지도

사용자가 선택한 2번 프로토타입을 v0.56.3에 적용했다. 네모 구획 대신 기존 지도 경계와 실제 지역 표시점을 같은 축 압축으로 옮긴다. 작은 지명/깃발 주변에 병사 묶음을 배치하고, 실제 이동/퇴각/점령 시간표를 재사용한다. 가짜 도로·인접 연결·전투 결과는 만들지 않는다.

지역 위치와 부대별 자리는 공세 시작에 고정한다. 참가자가 많은 경우 여백을 늘리며 기존 내부 확대/드래그/전체 보기와 지도 카메라 분리를 유지한다. 작은 전체도에는 지도 윤곽·지역·부대·현재 시야를 표시한다. 자유 지도의 내부 물 구멍도 유지한다.

관련 자동 검사: `node --test --test-isolation=none --test-reporter=spec tests/regional-field-v563.test.js tests/regional-battle-v562.test.js tests/battle-entry-v561.test.js` — 12개 통과. 실제 지도 방향/위치 고정, 초기 대기 위치, 대규모 부대의 좌표, 이동 연속성/경로 없는 재배치, 최종 병력/생사/소유권, 기존 다이스 기록 및 진입 처리를 확인했다.

단일 HTML은 `npm run release`로 생성한다. 전체 테스트나 장기 시뮬레이션은 반복하지 않으며 Android 실기기 검증은 포함하지 않는다. 게임 엔진·난수·저장 형식 변경 없음.

실제 패키징 HTML 복사본을 Chromium 1600×1000에서 열고 기존 160영토 경기(시드20261017, 9턴)를 가져온 뒤 네트워크를 차단했다. 실제 지도/7부대 표시, 내부 확대·드래그·지역 이름 클릭·전체 보기 복귀, 정지/재개, 요약/지도 복귀를 통과했다. 페이지 오류 없고 경기 상태 JSON은 전후 동일했다. 테스트 복사본에는 상태 확인용 접근자만 추가했으며 배포본에는 포함하지 않는다.
