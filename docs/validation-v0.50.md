# v0.50.0 전투 지역 강조·병사 애니메이션

기준: v0.49.0 / 엔진38. 사용자는 턴별 배속·4배속 전용 시간 조정 요청을 취소하고 그 이전 연출안만 구현하도록 지시했다. 해당 배속 기능은 추가하지 않았다.

## 구현

- 5연승 이상 또는 교전 시작 병력3배 이상 적 격파라는 기존 강조 조건을 유지한다. 결과 공개 순간 승자 컷아웃·전투창·월계수를 해당 영토의 편집 가능한battle 앵커에 표시한다. 화면 중앙/외곽 고정이 아니며 SVG 화면 투영을 사용한다. 위 공간이 부족하면 전투점 아래로 표시한다. 위도/경도나 실제 부대 위치를 고치지 않는다.
- 강조는 실제1200ms(등장150/확인900/퇴장150)이며 정지하면 같은 진행률을 유지한다. 결과 전/이후 다른 손실 단계에 중복 재생하지 않는다. 원래 카드/공지/집단군 판정 순서를 유지한다. 전신 컷아웃이 없는 인물은 기존 얼굴 사진을 쓴다.
- 카드 하단 양옆에 국가색의 작은 병사를 표시한다. 기존 카드의 이동/대형/포개기 변환 안에 있어 실제 카드와 함께 움직인다. 대기·걷기·공격·방어·피격·후퇴·전사는 공개된 사건/손실 단계에 연결한다. 병력0 생존 카드를 지휘관 전사로 바꾸지 않는다. 승상은 병사가 없다.
- 외형은 7만 표준 부대와 기존 병력차 보정의 차이+공격/방어 평균+개인 무장+역전승 별 점수다.4점 미만 농민병,tier1;4~14점 미만 창병,tier2;14점 이상 중보병,tier3. 교전 참가자는 교전 시작 병력/인물 능력을 사용한다. 실제 전투 점수나 병종 상성에 추가하지 않는다.
- 1~7만은1명,8~14만은2명,15만 이상은3명의 대표 병사로 규모를 표현한다. 집단군은 대표 카드에서 구성원의 외형을 사용하고 기존 보조 카드에 병사를 중복 추가하지 않는다. 병력 숫자는 기존 실제 숫자를 유지한다.

## 자료와 성능 범위

첨부 `troops-all (2).zip`의 원본 body/shade PNG42장,프레임 메타데이터,README를 assets/troops에 보존한다. 각 동작10프레임,3외형×7동작=210프레임이다. 실제 그림 영역만 국가색으로 합성한다. 생성 프롬프트나 동봉 국가표를 게임 규칙/세계에 주입하지 않는다.

원본 시트1920×640을 실행용825×276 WebP42장으로 줄였다. 실행용 파일 합계1,829,232바이트다. 미리보기GIF/완성색PNG/중복 base64는 실행본에 함께 넣지 않는다. scripts/prepare-troops.py로 보관된 원본에서 재생성할 수 있다. 앱은 Python이나 외부 요청 없이 내장 그림으로 동작한다.

MapAnimation의 공용 시계에서 필요한 프레임만 갱신하고 최대24개 국가색 합성 시트를 공유한다. 화면 밖은 그리기를 생략한다. 캐시24개는 전체 앱 메모리 상한이 아니며 원본 이미지 해독 중 일시적 메모리와 현재 카드 참조가 추가된다. 실제 기기 FPS나 무지연을 보장한 검사는 아니다.
