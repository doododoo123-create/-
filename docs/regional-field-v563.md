# v0.56.3 고정 전역도와 지역간 이동

v0.56.2의 기록 기반 전투/병력/생사/소유권 시간표를 유지하고 공간 배치만 추가했다. 모든 관련 지역은 공세 시작 때 고정된 도식 영역으로 배치한다. 현재 전장/소유색/부대 위치만 갱신한다. 대기 부대는 공세 시작 상태의 실제 지역에 남는다.

- regional-field-layout.js: 실제 지역 위치를 참고한 고정 도식, 실제 인접 연결, ID별 고정 부대 자리.
- regional-field-motion.js: 한 장수당 하나의 이동 궤적. 기록된 경로/도착지로 진격·후퇴하고 경로 없는 재배치나 경로 없이 기록된 위치 정리는 양 끝 페이드로 표현한다. 게임 좌표/거리/피로는 수정하지 않는다.
- regional-field-view.js: 전체 전역도, 현재 지역 강조, 실제 이동 중인 부대의 방향선, 전술창 전용 확대/드래그와 작은 전체도. 영역/지역 이름 클릭으로 확대, ‘전체 지역’으로 복귀한다. 내부 보기 상태는 plan별로 보관해 정지/재개 시 유지하며 게임 지도 카메라를 건드리지 않는다.
- 기본 전체 보기의 부대 표시는 작게 표시하고 확대 시 이름/병력을 자세히 보여준다. 확대 중 화면 밖의 이름은 숨기되 전체도에 부대 위치를 계속 표시한다.

`node --test --test-isolation=none --test-reporter=spec tests/regional-field-v563.test.js tests/regional-battle-v562.test.js tests/battle-entry-v561.test.js`

12개 검사 통과: 영역 누락/겹침/재배치 없음, 실제 초기 대기 위치, 단일 부대와 연속 궤적/재배치, 내부 확대 분리, 실제 종료 병력/생사/위치, 기존 지역별 중간 수치·소유권·재방문·역공·무방비 처리, 원본 기록/RNG 불변, 중요 사건 시계와 집결 진입 보호.

실제 패키징 HTML을 Chromium1600×1000에서 불러온 뒤 오프라인으로 시험 역사를 UI에서 가져왔다. 모든 지역 표시, 지역 확대, 내부 드래그,140×90 전체도 표시, 게임 지도 viewBox 불변, 전체 보기 복귀, A→B→C 전투 진행, 일시정지/재개, 요약/지도 복귀를 확인했다. 페이지 오류 없음. 초기 위치 보완 후 관련 검사와 같은 브라우저 흐름을 다시 통과했다.

사용자 요청에 따라 전체 테스트/장기 시뮬레이션을 반복하지 않았다. 실제128대128 렌더 성능이나 Android 기기는 검사하지 않았다. 게임 엔진·난수·저장 형식 변경 없음.
