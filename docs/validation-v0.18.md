## 배포와 한계

`npm run release`가 일반/모바일 두 HTML을 루트와 dist에 생성하며 각각 파일 내용이 일치한다. 외부 서비스·이미지 요청·CDN이 필요 없다. 클라우드 Chromium 관리 정책에서 file:// 열기를 차단하므로 실제 Windows 더블클릭과 물리 Android/iPhone 실행은 별도 확인이 필요하다. 브라우저 화면 크기 검증과 실제 기기 성능 측정은 구분한다.
