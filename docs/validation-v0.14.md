## 한계

화면 크기/회전 검사는 Chromium의 모의 화면입니다. 실제 Android/iPhone, Windows 더블클릭은 이 환경에서 시험하지 않았습니다. 관리형 Chromium의file:// 차단 때문에 HTTP로 받은 단일 HTML을 오프라인에서 재로딩해 검증했습니다. 낮은 높이의 가로 화면에서는 창이 가리지 않도록 지도 배율을 낮추므로 지도 카드는 작아질 수 있습니다. 자동 추적을 끄고 수동으로 확대하거나 전체 정보 표시를 선택할 수 있습니다. 경량판의 압축 배경을 크게 확대할 때 생기는 화질 차이는 기존과 같습니다.
