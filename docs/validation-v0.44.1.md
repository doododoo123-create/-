# v0.44.1 자동 진행 중단 수정과 검증

검증일: 2026-10-31. v0.44.0의 지도·인물·전투 화면을 유지한 오류 수정판이다.

## 원인과 수정

수도가 함락된 뒤 한 연속 공세에서 영토를 더 잃으면, 현재 수도를 고르는 결과가 다시 바뀔 수 있었다. 국왕의 위치가 여전히 자국 영토이면 기존 정리 함수가 복귀를 생략하여, 차례 종료 시 국왕과 수도의 위치가 어긋났다. 이때 `턴 처리 뒤 규칙 상태가 일치하지 않습니다` 오류로 차례 생성이 중단됐다. 255턴 상한이나 8비트 턴 수 문제가 아니다.

새 차례에는 연속 교전 정리 때 기존 국왕 복귀 함수를 호출한다. 살아 있는 현역 국왕만 현재 수도로 복귀하며, 이동은 기존 `royal_return` 사건으로 기록한다. 추가 주사위나 병력을 만들지 않고, 전투·손실·점령 한도와 국왕 방어 범위를 유지한다. 사망하거나 멸망한 국왕을 부활시키지 않는다.

## 기존 경기와 기록

수정 적용 여부를 새 차례의 `controls.royalCapitalSync:true`에 기록한다. 이 값이 없는 과거 차례는 이전 계산과 이동으로 재구성한다. 완료된 기록·초기 세계를 다시 쓰지 않으며, 기존 자동 저장이나 역사 JSON을 불러와 바로 이어갈 수 있다. 새 실행은 필요하지 않다. 엔진34·세계2·진행1·역사2 형식은 유지한다.

HTML을 기존 파일과 같은 위치·이름으로 교체하면 그 위치의 브라우저 저장을 읽는다. 다른 위치나 브라우저에서 열어 자동 저장이 보이지 않으면, 이전 HTML에서 전체 역사를 내보내고 새 HTML의 **불러오기**로 이어갈 수 있다.
