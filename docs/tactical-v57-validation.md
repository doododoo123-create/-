# v0.57.0 검증 기록

## 최종 실행 결과

- 전체 자동 검사 **667개 통과**, 최종 접촉 배정 수정 후 관련 **42개 통과**, 진입 연결 수정 후 **26개 통과**.
- JavaScript **360개 파일 구문 검사 통과**.
- 오프라인 실제 160영토 지도 212% 및 2/4/8배속에서 지도 복귀·동시 후퇴·순차 점령·사운드 배속 정책 검증.
- 실제 시간 녹화 중 평균 RAF **35.5회/초**, 실제 Canvas **22.5회/초**, RAF 간격 p95 **66.6ms**.
- 별도 녹화 없는 측정(배속: RAF / 실제 Canvas): 1배: 57.6 / 31.0회/초, 4배: 37.6 / 37.4회/초, 8배: 55.0 / 55.2회/초.

위 수치는 이 검증 환경의 측정값이며, 모든 PC·모바일에서 30fps 이상이라는 보장이 아니다.

## 성능과 한계

측정 환경은 Linux 클라우드 컨테이너의 headless Chromium, 1280×760, DPR1, 초기 병사 그림 960명이다. 녹화와 동시에 잰 실제 RAF 간격을 기록한다. 전술창은 재생 시간 32ms를 기준으로 Canvas를 갱신하므로 RAF 호출 빈도와 실제 그림 갱신 빈도를 구별한다. 병사 원본을 매번 축소하지 않고 실제 화면 배율에 맞춘 작은 프레임 캐시를 사용한다. 원본 이미지 파일의 화질이나 게임 병력 수를 낮추지 않았다.

이 측정은 특정 PC나 모바일의 최저 프레임을 보장하지 않는다. 60만 장수·재탈환 자료는 화면 구조를 검증하기 위한 것이며 실제 게임의 지휘한도·발생 확률을 입증하지 않는다. 기존 원화에 없는 정면/후면 시점은 새로 그리지 않았으며, 측면·사선과 반전을 사용한다.
