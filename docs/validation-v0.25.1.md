# v0.25.1 판정 소리 · 2026-10-25

파칭코 rolling 클릭·주사위 rolling(모든 음색/틱)·양수 보정 merging에 cue gain1.5를 추가했다. v0.25의 전체/음원별 보정 위에 적용한다. 일반 UI 클릭·착지·확정·감산·다른 효과음,음량 설정/음소거/녹화용/고배속 간소화,국경·초기 배치·규칙·엔진·저장 형식을 유지한다. 새 실행이 필요 없다. 미리듣기 원본보다 해당 게임 장면을 강조하는 조정이다.

## 확인

- 기존 오디오 검사27개 통과: `node --test tests/audio-v24.test.js tests/loudness-v25.test.js`.
-182개 JavaScript 구문 검사 통과: `npm run check`.
- 이전 태그 코드와244가지 음색/배속/단계/보정 경우를 비교했다.164개 cue 중 요청한78개만 gain1.5가 추가되고 나머지 속성/비대상 cue가 동일했다. 시점·횟수·길이는 유지한다.
- 일반판/모바일 경량판의 실제 오프라인 HTML에서 국왕 선택 파칭코가 native AudioBufferSourceNode를 통해1.5배 clip gain으로 재생된다. 버전v0.25.1,JavaScript 예외0.
- native OfflineAudioContext와 실제 앱 mixer/컴프레서를 통과한 출력 비교(전체50%):파칭코·기본 굴림·가산 각각 RMS 비율 약1.500000. 전체100%에서도 피크가1 미만이다. 수치는 신호 측정이며 물리 청감 평가는 수행하지 않았다.
