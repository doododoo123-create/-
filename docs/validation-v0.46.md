# v0.46.0 망국 인물 재등용·권역별 유지·고정1초 판정표

기준은 v0.45.1이다. 사용자가 승인한 세 항목을 일반 단일 HTML에 함께 반영했다. 원본 지도/영토/초상·소리 파일과 기존 화면 최적화·국왕 방어/복귀·천하통일 공지를 유지한다.

## 동작

- 확정 전체 판정표는 배속/추가 이동 가속에 관계없이1000ms다. 일시정지하면 남은 시간을 보존하고 다음 장면에서 선택 배속으로 복귀한다. 다음 장면이 apply인 경우도 추가 departing 대기를 넣지 않는다. 기존 지도 연출 선행·표 틀/스크롤·개별1대1을 유지한다.
- 멸망한 국가에서 임관했던 생존 장군을 새 지휘직 또는 기존3회 대기를 마친 후임 자리에 우선 등용한다. 원래 인물의 이름·사진·공격/방어/개인 능력·기동·개인 지휘 보정·승수/역전승/별·생애 ID를 유지한다. 소속/자리/주둔지는 수령국을 따르고 병력은 새 국가에서 충원한다. 임시 혼란/정비는 해제한다. 국가 기술/보급 보정은 새 국가의 값이다.
- 망국 후보의 사진을 다른 이름에 대여하지 않는다. 원래 인물과 나중에 만들어진 인물이 같은 사진을 갖는 구형 저장은 원래 인물을 우선 보존하고 빈 사진으로 한 번 정리한다. 전사자는 제외하고 원래 슬롯의 transferredTo로 반복/동시 등용을 막는다. 기존 전투 개인 ID를 이어 이전 국가의 주요 전투를 조회한다.
- 수도권과 고립지 각각 육지 연결 영토 수×5만 유지 한도다. 장군은 담당 주둔지,왕/미배치/재편 대기병은 수도권에 합산한다. 국가 총병력이 총한도보다 작아도 고립지는 독립적으로 초과할 수 있다. 계절 종료 때 각 권역 초과량25%를 만 단위 반올림(초과 시 최소1만/초과량 이내)하고 비례 차감한다. 국가 탈영을 추가로 중복하지 않는다.
- 신규 충원/모병도 권역 여유 공간 안에서만 생성한다. 기존 수도 풀은 수도권에서 배분한다. 각 지휘관의 기존 박스에 권역 크기·한도·실제 탈영을 한 번 표시하고,대기 풀 손실은 왕 본인 병력과 구분한다. 한도와 같으면 탈영0이고 탈영으로 병력이0이 되어도 장수는 생존한다.
- 엔진37은36 이하 저장을 읽는다. 새 차례 regionalMaintenance/recruitExiles와 첫 신원 경계 exileIdentities를 기록한다. 기존 초기 세계/완료 기록은 당시 규칙/RNG로 재구성하고 새 차례부터 지속 상태를 적용한다. 원본D10 예제는 보존한다.
