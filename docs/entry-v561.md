# v0.56.1 집결·대치·전술창 진입

56버전을 기준으로 지도에서 전술창으로 들어가는 부분만 수정했다. 이후 버전의 전술/명령/병사 축척 변경은 가져오지 않았다.

- 다른 전선의 집결·진군은 해당 전투 직전에 보여준다. 이동 경로와 실제 거리는 원본 기록을 사용한다.
- 뒤 전선의 대기 위치와 앞 전투의 소유권·병력을 보존한다. 다른 전선 준비 때문에 과거 지도로 돌아가지 않는다.
- 대치부터 전술창 진입까지 표시용 집단군을 유지한다. 실제 초기 수비 장수가 여러 명이면 집단군으로 묶고, 혼자 수비하는 장수는 개인으로 표시한다. 원본 집결 메타데이터가 없는 경우에도 실제 첫 전장의 수비자들을 읽는다.
- 양측 대표와 구성원 카드를 전투 아이콘 양옆에 배치한다. 이후 전술창이 그 아이콘 위치에서 확대된다. 기존 재생 시계를 사용하므로 정지·재개·배속에 맞는다.
- 내부 전투 계산용 해제 이벤트를 앞당겨 지도에 노출하지 않는다. 전투 판정·난수·손실·거리·피로·영토 결과와56 전술창 내부는 그대로다.

`entry-preparation.js`가 전선별 준비와 대기 위치를, `battle-entry.js`가 대치 시 표시할 실제 참가자를 구성한다. `army-presentation.js`는 진입 중 표시용 집단군을 읽으며 `mass-battle-animation.js`는 아이콘 기준 확대만 추가했다. 지도 결과 재생과 사운드/저장/엔진은 변경하지 않았다.

관련 자동 검사42개 통과: 4대4 대치 유지, 집단군 대 개인, 복수 전선 순서·대기 위치·소유권 보존, 실제 장수/RNG/결과, 기존 지도 후퇴/점령·왕 방어·전사·정지/배속. 추가한3개 검사는 마지막 위치 정리 후 다시 통과했다. 변경 JavaScript8개도 구문 검사했다. 전체 장기 시뮬레이션 검사는 이번 화면 전환 패치에서 반복하지 않았다.

실제 단일 HTML을 Chromium에서 불러온 뒤 네트워크를 끄고 역사 재생을 확인했다. 아이콘 양옆의 두 집단군, 아이콘 기준 확대·정지/재개·지도 복귀까지 확인했고 페이지 오류는 없었다. [대치 화면](v561-duel.png).

```sh
node --test tests/battle-entry-v561.test.js tests/studio-v56.test.js tests/studio-v55.test.js tests/mass-battle-v52.test.js tests/mass-battle-v53.test.js
npm run release
python tests/battle_entry_v561_smoke.py
```

앞으로도 화면의 작은 수정은 관련 기능 검사와 필요한 브라우저 확인에 집중한다. 엔진·저장 형식·공통 규칙을 변경하거나 영향 범위가 넓을 때 전체 검사를 수행한다.
