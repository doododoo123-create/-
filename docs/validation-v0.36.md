# v0.36.0 검증

검증일: 2026-10-28 (한국 시간). v0.35 기반이며 엔진31/세계·진행·역사 형식과 실제 판정은 유지하고 관전 재생만 수정했습니다.

- `npm test`: **476개 통과, 실패0**. 신규10개는1.5배 지도/다이스 시간 유지,무방비 영토의 단일 진입→즉시 점령/외국 영토 방문 표시,개별1대1/반복 상대,1대다의 실제 수비 인원,결성 단계/군령 큐,중복 재생/음소거,불필요한 문구 제거/보정 유지,게임 상태·RNG 보존,세계/시드로 재구성되는 세 종류 역사,왕/일반 카드의 결성 효과 누출 방지를 검사합니다.
- 공개된 수비 집단군 머리글을 정리한 뒤 관련21개 검사를 다시 실행해 모두 통과했습니다.
- `npm run check`: JavaScript **242개 파일 구문 검사 통과**.
- `python tests/studio_v36_smoke.py`: 완성 HTML을 일반판1600×1000/모바일844×650/모바일390×844로 오프라인 실행했습니다. 각 화면에서 실제 집단군/개별1대1/무방비 세 종류의 역사를 불러와 재생했습니다.
- 실제 결성 표시/확대/보조 등장 중 정지하면 변형과 투명도가 그대로 유지되는지 확인했습니다. 결성 효과가 없는 시작/다이스 단계에 잘못된 강조가 생기지 않는지 검사했습니다. 음향은 별도 큐/디렉터 검사에서 같은 결성의 재렌더·정지/재개 중복 방지와 음소거를 확인했습니다.
- 다이스 회전·보정 비행·최종 점수 단계에서 다이스가 배경 박스 안에 있고,보정 비행도 경계를 넘지 않는지 실제 화면 좌표로 검사했습니다. 중앙 쪽 상단 승패/손실 배치와 ‘눈금→보정 합산’ DOM 제거,우세 표시는 유지했습니다.
- 1대1에 군 대결표/대표 카드가 없고 기존 개별 D30 창이 나오는지 확인했습니다. 무방비 영토는 도착 직후 같은 카드 위치에서 빗금이 이어지며 중간 VS/자국 복귀가 없고,재생 중 현재 저장이 그대로인지 확인했습니다.
- `STUDIO_TEST_LABEL=v36 python tests/studio_v29_smoke.py`: 양쪽 HTML에서 내장 상업 이용 글꼴·라이선스,5MiB 초과 세계/취소,전체 역사 가져오기·재생·내보내기,실제 이전27역사 이어하기,공유/전체 경로·혼란 표시,손상 파일 거부·기존 저장 보존·재실행 복원을 통과했습니다.
- 브라우저 앱 예외와 외부 요청 실패 **0건**입니다. 효과음42개/폰트/지도·초상 원본과 엔진 파일은 변경하지 않았습니다. 현재와 이전 기록 모두 새 실행 없이 새 관전 화면을 사용할 수 있습니다.
