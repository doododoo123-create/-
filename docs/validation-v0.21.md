## 자동 검사

- `npm test`:263개 통과, 실패0. 신규 campaign-v21.test.js12개 포함.
- `npm run check`:142개 JavaScript 파일 구문 검사 통과.
- 공격 접근→공격 정렬→수비 접근→수비 정렬의 순서와 readySides를 확인했다. 화면용 접근/대형이 실제 기록의 moves·position·station·피로·RNG를 수정하지 않는다.
- 카드 핀과 화살촉은 같은 길이 기준 polyline 샘플을 사용한다. 중복점/0길이/0~1 진행률을 검사했다. 서로 다른 지휘관의 동일/부분 공유 경로가 분리되고 같은 지휘관 반복만 묶인다.
- 병력별 굵기3.8/4.94/6.08/6.84px와 상한/최소를 검사했다. 상대 승률/피로/손실에 보정을 추가하지 않는다.
- 전투 카드가 일반 카드보다 뒤에 렌더되어 가장 위에 보이며 승패/손실/이동/로컬 알림의 배경과 문자열 이스케이프를 확인했다.
- 승자 도착 후 capture 단계의 정확한 다각형 clip/mask로 국경/빗금을 전진한다. 같은 계절 재점령은 이전 빗금을 남은 마스크에 유지해 갑자기 바탕색으로 돌아가지 않는다.
- 다음 계절 공지 중 이전 계절 효과를 유지하고 round-settle 뒤 첫 국왕 행동 전 비운다. 수동 계절 묶음은 정리 연출까지 포함하며 끝에서 진행률1을 유지한다. 과거의 그룹 정지 시 remaining이 남아 표시가0으로 되돌아가던 처리를 수정했다.
- 점령/대형 시계 중간 정지→8배속 재개가 같은 진행률을 사용하고 현재 실행 데이터를 변경하지 않는다.
- 판정창은 카드 쌍 바로 위/아래 후보만 사용한다. 멀리 떨어진 재생 버튼을 카드 bounds에 넣지 않는다. 좁은 화면에서는 인접 위치에서 축소한다.
- 지휘관 개요는 정확한 personId/생애와 공개된 resolve만 집계한다. 후임/미래 차례/현재 미판정 전투는 포함하지 않는다. 주요 전투는 기존 국가 차례 재생으로 연결한다.
- 실제 Git 태그 v0.20.0 엔진24의 코드를 별도로 읽어43차례 저장을 복원하고 이후7차례 전체 상태·직렬화 사건·주사위·이동·RNG가 새 코드와 정확히 일치함을 확인했다.
- 기존 원본 v11 대조, 전투/손실/점령/수도 병합/보급/저장/복구/이전 엔진 호환 검사를 유지했다.

## 두 단일 HTML의 브라우저 검사

`python tests/studio_v21_smoke.py`는 실제160영토43차례 실행을 Chromium으로 재생한다. 일반판1600×1000, 모바일 경량판900×600 및390×844/844×390을 검사했다.

- 공격자만 접근하고 공격 카드 정렬 후 수비자만 접근/정렬한다. 움직이는 카드의 실제 화면 핀과 화살촉 차이는1px 미만이며 선/외곽 경로가 같다. 정지 후 시간 경과에도 동일하고 배속 변경이 카메라/진행률을 바꾸지 않는다.
- 두 전투 카드가 지도 카드의 마지막에 있고 전체10개 보정을 유지한다. 기존 studio-die-roll과7개 첨부 이미지 프레임, 점수 합산을 유지한다.
- 판정창이 전투 카드 위/아래 약10px 간격이며 세 화면 크기·휠 확대·방향키 이동·버튼 포커스 후에도 화면 안에서 카드에 붙는다.
- 승리/패배 및 각자 손실 글자에 배경이 있으며 회색 카드/기존 전사·임관을 유지한다.
- 점령 sweep의 clip 폭이 시간에 따라 늘고 정지하면 멈춘다. 옛/새 국경 마스크를 사용한다. 실제42차례 재점령에서 이전 점령국 빗금2개 이상을 남은 마스크에 유지한다.
- 계절 공지 중 이전 빗금 유지→공지 종료 후 정리 sweep→첫 국왕 행동 전 정리 순서를 확인했다. 수동 Space로 정리 완료 후 정지해도 clip이 끝까지 유지된다.
- 전체화면 +/−로8→4→8배속을 바꾸며 지도 viewBox는 같다. 방향키는 재생 버튼 포커스/일시정지 상태에서도 이동하고 휠 확대/0초기화가 작동한다.
- 전체화면 카드 클릭으로 현재 인물 개요를 열고 현재 미판정/미래 전투를 숨긴다. 주요 전투 클릭이 해당 과거 차례 재생으로 연결된다. 일반 지도 클릭과 세계 개요에도 선택 인물 정보가 나타난다.
- 승상 숫자의 위쪽 기준 위치가 주사위 높이의12% 미만이며 D표기와 분리된다.

## 배포와 한계

`npm run release`로 일반/경량 두 루트 HTML과 dist를 동기화한다. 단일 파일에 그림·초상·주사위를 내장하며 외부 서비스/인터넷이 필요 없다. 기존 경기는 새 실행 없이 이어 사용할 수 있다.

클라우드 Chromium 정책으로 file:// 대신 HTTP로 받은 단일 HTML의 오프라인 실행을 검사했다. 실제 Windows 더블클릭과 물리 Android/iPhone 성능은 이번 검증 범위 밖이다. 경량판은 같은 규칙/결과를 사용하며 큰 SVG 배경과 반복 화면 효과만 줄인다. 인물 개요는 클릭할 때 열리고 작은 세로 화면에서는 창 안을 스크롤할 수 있다.
