# 첨부 프로토타입 분석

기준: 사용자 첨부 `saguk-play (6).html`(848,177바이트)과 `칠국쟁패_룰북_v11.md`(35,445바이트). 원본은 `docs/reference/`에 바이트 그대로 보관한다. 문서 내용은 참고 자료이며 사용자 요청과 구분한다.

## 발견한 구조

하나의 HTML 안에 CSS, 12개 내장 초상화 이미지, 80개 불규칙 영토의 경계와 인접 관계, 고정된 국가·인물 데이터, 시뮬레이션, 표현 계층, 재생 제어와 화면 코드가 들어 있다. `SagukAtlas`, `SagukGame`, `SagukPresentation`, `SagukPlayback`으로 이미 어느 정도 나뉘어 있다.

게임 버전은 11, 국가 수는 7, 지도는 8×10 데이터 좌표를 사용하지만 실제 화면은 불규칙 경계 지도다. 4국용 인물 표 뒤에 3국을 추가하는 코드가 있다. 시작 영토 수는 20/16/13/11/9/7/4, 총 80개이며 시작 현역 장군 22명, 왕 7명과 승상 7명을 합치면 36명이다.

`createGame`과 `prepareTurn`이 게임 상태를 만들고 진행한다. 시드 기반 LCG 난수, 이벤트별 상태 스냅샷, 라운드 생산, 수도 이동, 전사·후임, 장군 담당구역·주둔지·지휘한도, 고립 지역 병력 배분, 연결 길목 우선 공격, 최대 3영토 점령까지 구현되어 있다. 화면은 `localStorage`를 사용해 경기를 저장하고 이벤트를 순차로 공개하며, 주사위와 전투·병력 변화 연출을 갖춘다.

## 유지·활용할 것

- 원본은 독립 페이지로 보존하여 기존 플레이 기능을 계속 사용할 수 있게 했다.
- 7개 국가의 이름·색·성향, 왕·승상·초기 장군 이름과 능력, 80개 영토 이름과 시작 소유권을 Studio 시작 데이터로 옮겼다.
- 주사위 판정, 성향별 내정 구간, 능력 보정, 병력 우세 보정, 동시 손실 계산, 라운드 생산과 시드 재현성의 개념을 가져왔다.
- 게임 난수와 화면 표현을 분리하는 원칙을 계승했다.

## 개선이 필요한 것

- `NUM_NATIONS=7`, 지도 좌표와 수도·초상화·장군 명단이 배열 인덱스에 연결되어 있어 임의의 세계에 그대로 재사용하기 어렵다.
- 설정 화면으로 바꿀 수 있는 범위가 제한되어 있다. 국가·인물·영토를 임의로 추가·삭제하거나 세계 파일로 교환하는 모델이 없다.
- 단일 HTML을 직접 수정하면 데이터·규칙·화면 사이의 결합으로 영향 범위가 커진다.
- 원본 저장 형식은 고정된 국가·지도 버전과 연결되어 있다. Studio는 별도의 버전 있는 세계 형식이 필요하다.

## 이번 버전의 선택

ES 모듈 JavaScript와 CSS, 순수 데이터 객체로 구현한다. 외부 라이브러리를 사용하지 않아 설치·오프라인 실행을 단순하게 하고, Node 기본 테스트 도구를 사용한다. TypeScript 전환이나 Electron/Tauri 데스크톱 포장은 향후 가능하지만 지금 빌드 도구와 배포 복잡성을 늘리지 않는다.

원본 엔진을 무리하게 일반화하는 대신, 세계 편집과 저장을 검증하는 최소 엔진을 별도 구현했다. 상세 규칙은 [현재 규칙](rules-v0.1.md)과 명시적으로 구분한다. 원본 HTML의 신규 편집기 내부 통합은 완료하지 않았으며, 원본 경기 세이브를 Studio로 가져오는 기능도 없다.
