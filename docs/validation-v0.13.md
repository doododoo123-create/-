## 성능 비교의 범위

같은 Chromium·900×600 화면에서 CPU를4배 느리게 설정하고 세계 개요 화면을12번 갱신했습니다. 첫2회는 준비 구간으로 제외한 중앙값입니다.

| 측정 | 일반판 | 경량판 |
|---|---:|---:|
| 화면 갱신 JavaScript 처리 중앙값 | 229.5ms | 102.45ms |
| 단일 HTML 크기 | 9,755,309바이트 | 7,360,689바이트 |

이 조건에서는 갱신 처리 시간이 약55% 줄었습니다. 이 값은 전체 화면의FPS·전투 처리 속도·실제 휴대전화 성능을 뜻하지 않으며 환경별 차이가 있습니다. 경량 지도 배경은120,290바이트이고 일반판의벡터 원본은 유지합니다.

## 사용 시 확인할 범위

실제 Android/iPhone·Windows 더블클릭은 이번 환경에서 시험하지 않았습니다. 관리형 Chromium은file:// 진입을 차단하므로 HTTP로 받은 단일 HTML을 네트워크 오프라인에서 재로딩해 확인했습니다. 경량판은 크게 확대하면 배경 그림의세부 묘사가 벡터 일반판보다 흐려질 수 있습니다. 경량판이 불편하면 일반판을 선택할 수 있고 기존v0.12.0 태그도 보존합니다.

HTML 파일 주소/브라우저별 자동 저장 공간이 달라질 수 있습니다. 세계는 JSON으로내보내기/불러오기를 지원하지만 역사 JSON을 화면으로가져오는 기능은 후속 범위입니다. 두 파일의자동 저장 공유를 약속하지 않습니다. 새 이름/전적 보정은 편집 세계에서새 실행을 준비해야 적용되며 진행 기록은당시 규칙으로 유지합니다.
