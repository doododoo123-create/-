## 장수와 저장

기본 규칙의 장군당8영토로 현역 장군6/4/6/2/2/2/1명,합계23명이다. 나라별 기존 인물·능력·초상 선택을 유지하고 부족한 두 자리는 초기 엔진이 생성한 인물로 준비한다. 이들의 실제 시작 위치·주둔지·관할 영토를 세계의 deployment에 넣는다. 각 영토는 정확히 한 지휘관이 담당하고 주둔지는 본인 관할이다.

기존 국가별 초기 총병력은10만 그대로이며 배치가 병력을 만들지 않는다. 기존 예비병 분배 때문에 신규 지휘관 일부는0만으로 시작해 이후 충원을 받는다. 기본 지휘한도·상한·승수·전투·점령 규칙은 유지한다.

새 세계 기본과 새160대륙 템플릿만 이 배치를 사용한다. 기존 편집 세계는 세계 개요/시작 배치의 새 영토 배치 적용 버튼으로 전환하고 새 실행으로 플레이한다. 진행 경기/기록은 유지하며 적용 전 배치로 되돌리기는 해당 세션에서 가능하다. 새 세계 만들기/가져오기는 이전과 같이 작업 세계를 교체한다.

## 음량

기본 출력 배율1.5는 사용자 전체 음량 슬라이더 뒤에 적용한다. 기본50%를 임의로75%로 저장하지 않으며,기존 사용자 설정도 유지한다.42개 원본 MP3는 재인코딩하지 않았다.

음원별50ms 스테레오 RMS 구간에서 최강 구간보다10dB 이내인 구간만 평균한다. 기존 manifest volume을 포함한 유효 음량을 기준으로 목표−26dB,보정0.7~2.75로 제한한다. 긴 무음/잔향 때문에 짧은 클릭을 과도하게 키우지 않는다. 원본 자체/설정 gain을 포함한 유효 구간 범위는−34.1749~−21.5785dB에서−26.0005~−24.6766dB로 좁아졌다. 종류별 음량과 녹화용 차이는 유지한다.

합산 뒤 DynamicsCompressor(threshold−5dB,knee4,ratio20,attack0,release0.08초)로 큰 순간 출력을 줄인다. 이번 실제 브라우저 검사는42개 원본의 native 해독/출력과 최대 음량4음원 합산을 확인했으며,물리 청감 평가는 수행하지 않았다.
