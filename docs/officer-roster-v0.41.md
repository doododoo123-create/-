# v0.41 기본 장수 성향 배정

기본 시나리오의 이름·초상·병력·주둔지를 유지하면서 성향과 공격/방어/기동을 부여했습니다. 후보 장수도 포함하며, 사용자 세계의 장수는 ID로 일관되게 배정합니다. 성향 선택 후 개별 수치는 인물 관리에서 편집할 수 있습니다. 기본 수치에 기존 능력의 부호에 따라 −1/0/+1을 반영하고 −4~+4로 제한했습니다. 후임은 새 생애 기준으로 배정하며 전임자의 전적·별을 물려받지 않습니다.
