## 배포와 범위

`npm run release`로 두 루트 HTML과dist를 생성하고 바이트 일치를 확인했다. 일반13,001,094바이트,경량10,606,474바이트다. 설치·외부 서비스·로그인 없이 동작하고 새 CSS도 HTML에 내장한다.

검사는 클라우드 Chromium의HTTP/오프라인 모드다. 실제 Windows 더블클릭과 물리 Android/iPhone의 프레임 속도는 이번에 측정하지 않았다. 차례의 인위 제한은 없지만 장기 기록은 해당 브라우저의 저장 공간을 사용한다. 역사 파일 가져오기/진행 중 배치 수정/국왕의 수도와 분리된 행군은 이번 범위에 추가하지 않았다. 새 규칙/배치는 **v0.23 적용 → 새 실행**에만 반영하며 기존 경기의 결과를 중간에 변환하지 않는다.
