# v0.51.2 밀집 병사 대형

사용자는 병사 그림의 일부 겹침을 허용하고 거의 붙은 대형을 요청했다. 표시 크기40.5는 그대로 두고 좌우 간격을36~56→18,앞뒤 간격을48→28로 줄였다. 모든 동작에 동일한 간격을 쓰며 무기/방패와 뒷줄 하체의 일부 겹침을 허용한다. 뒷줄부터 그려 앞줄 얼굴을 가리지 않게 하고 카드 높이·부대 타원·전투 폭도 새 대형에 맞췄다.

지휘관별 그림 수/등급/동작/국가색과 카드 정보,224픽셀 원본·줌/DPR 캔버스,실제 전투·이동/피로·병력·난수·저장·배속은 유지한다.

## 확인

- 관련 병사/카드/대형·카메라·선택 턴 촬영·전투 표시45개 통과,실패0. 개인별2+1+3=6 유지,이동 중 분리/집단군 중복 합산 방지,24명까지 수 보존,공격 대기 동일 간격,원본 포즈가 캔버스 밖에서 잘리지 않는 여백을 포함한다.
- 변경 JavaScript6개 구문 검사 및 git diff --check 통과. 일반 단일HTML 생성.
- 최종 일반HTML을 오프라인 Chromium1600×1000/DPR2에서 검증했다. 실제 기록 가져오기·병사 표시/카드 정보·정지 시 픽셀 유지·캔버스 CSS 크기×DPR·500% 확대/카드 상세 클릭·전투 지역 강조/시점 이동/고정1.2초를 통과했다. 앱 예외/요청 실패0이다. 가짜 시계를 사용한 검증이다.
- 루트 실행HTML과dist 파일 바이트가 일치한다.
