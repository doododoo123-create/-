# v0.57.1 선택 턴 녹화의 집단군 전술화면

이번 변경은 사용자가 마지막으로 승인한 **6번만** 적용한다. 앞서 제시한 전술 전개·축척·전장 배치·기존 지도 원복 등 1~5번은 이번에 변경하지 않는다.

역사 기록에서 녹화할 턴을 체크하는 곳에 **집단군 전술화면** 체크칸을 추가했다. 처음에는 켜져 있다. 선택은 이 브라우저에 저장되고 ‘선택한 턴 재생’을 누를 때 해당 재생 세션에 적용된다.

- 켜기: 기존 전술화면과 결과표를 보여준 뒤 지도 결과 연출로 이어진다.
- 끄기: 집단군 전술 계획 생성·VS 진입·전술창·결과표를 건너뛰고, 기존 지도 이동·동시 퇴각·영토 점령·수복 결과 연출로 바로 이어진다.

동일한 `massBattleRecap`과 원본 세계·사건·이동·영토 공개 장부를 사용한다. 일반 관전과 일반 역사 재생에는 이 녹화 설정을 적용하지 않는다. 전투 판정·주사위·게임 RNG·손실·승패·저장된 영토 결과를 바꾸지 않는다. 기존 일반 일대일 전투의 처리도 유지한다.

`selected-battle-mode.js`는 녹화 세션 옵션과 체크칸을 담당하고, `filming-settings.js`는 브라우저 선택을 보관한다. `playback.js`는 map-only 옵션을 전달하는 한 곳만 수정했다. `mass-battle-scenes.js`는 꺼진 경우에도 개별 주사위로 돌아가지 않고 기존 지도 recap으로 연결한다. v56 보호 모듈 검사는 승인된 옵션 전달 한 구문만 투영하고 나머지 바이트와 기존 42개 지도 장면을 계속 대조한다.

검증:

- 관련 자동 검사 36개 통과: 초기값·선택 저장·세션 제한·재생 복원·켜기/끄기의 동일한 지도 장면 및 최종 세계.
- 실제 단일 HTML을 읽은 뒤 네트워크를 끈 Chromium에서 선택 저장, 꺼짐 재생의 전술창/개별 주사위 생략, 지도 후퇴·점령, 다시 켠 전술화면을 확인했다. 새 페이지에서도 선택 값이 유지되며 페이지 오류는 없었다. JavaScript 362개 파일 구문 검사도 통과했다. 화면은 `v571-recording-choice.png`, `v571-recording-on.png`에 보관했다.

실행 파일은 루트의 `사국쟁패 Studio.html`이다. 다운로드해 브라우저로 열면 된다. 개발 실행은 `npm start`, 해당 검사는 `node --test tests/selected-battle-v571.test.js tests/filming-v47.test.js tests/tactical-v57.test.js tests/studio-v56.test.js`로 실행한다.
