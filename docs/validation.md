## 구분해야 할 한계

- Playwright 기본 브라우저가 없어 시스템 Chromium을 사용했다. 추가 브라우저 다운로드는 네트워크 정책상 403이어서 사용하지 않았다. 애플리케이션은 외부 패키지나 외부 네트워크가 필요 없으므로 추가 허용 도메인은 요청하지 않았다.
- 관리형 Chromium은 `file://`를 차단한다. 이 정책을 바꾸지 않았으며, Windows에서 더블클릭해 파일을 여는 동작은 직접 확인하지 않았다. 단일 HTML을 HTTP로 읽고 이후 오프라인으로 동작하는 것은 검증했다.
- 외부 녹화 프로그램으로 영상 녹화, 실제 Edge/Safari, 과거 역사 재생/재개는 검증하지 않았다. 후자의 두 기능은 구현 범위에도 없다.
- 테스트를 통과한 것은 현재 클라우드 인스턴스와 배포 산출물이다. 환경 설정 저장은 별도이며 환경 게시·새 클라우드 작업 복원은 실행하지 않았다.

브라우저 검증 스크립트는 선택 도구로 Python Playwright와 로컬 Chromium이 필요하다. 일반 프로그램 실행에는 둘 다 필요 없다. `CHROMIUM_EXECUTABLE`과 `STUDIO_TEST_URL`로 테스트 경로/주소를 바꿀 수 있다.
