# v0.48.0 선택 턴 촬영 검증

- 기존 전체 자동 검사: 62개 테스트 파일 통과. 새 selected-filming-v48.test.js도 별도 통과.
- JavaScript 306개 파일 구문 검사 통과. 최종 지도 화면 변경은 브라우저에서 실제 실행했다.
- 새 연동 검사는 실제 app.js 재생/완료/복귀 함수와 TurnPlayback, replayTurn을 실행한다. 1·3턴만 복원, 마지막 정지, 종료 후16배속 정지 유지, 이전 선택 턴, 현재 presentation·카메라 복귀, 경기 JSON 불변을 확인했다. 300턴 선택 정렬·중복/진행 중 턴 제외도 확인했다.
- Chromium/Playwright 1600×1000에서 생성된 단일 HTML을 로컬 HTTP로 열었다. 실제 화면에서5턴 생성 후1·3턴 체크→촬영→선택 턴 이동→마지막 정지→16배속 변경→이전 선택 턴→현재5턴 복귀를 검증했다. 선택 체크 유지, 제거된 도구 없음, JavaScript 페이지 오류 없음도 확인했다. 장면 끝 이동에는 기존 결과 건너뛰기를 사용했다.
- 이 환경의 Chromium 정책은 file:// 탐색을 차단하므로 브라우저 검증은 로컬 HTTP에서 수행했다. OBS 실제 녹화와 Android 기기 실행은 이번 검증 범위가 아니다.
- 촬영 컷아웃 자료 원본은 보관하되 실행 HTML에서 해당 이미지 모듈을 제외했다. 실행본 약21.4MB이며 외부 CDN/로그인을 게임 실행에 요구하지 않는다.
