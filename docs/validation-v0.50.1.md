# v0.50.1 병사 중심 배치

사용자가 승인한 비교 시안의 비율을 적용했다. 병사는 표시 높이18→54(3배),지휘관 카드와 상태 표시는0.75배다. 기존 카드 핀 끝35 위치가 병사 발의 기준이며,작은 카드는 위로 들어올려 이름/병력/별/국가색/왕관/상태/클릭 상세를 유지한다. 승상의 카드에는 병사를 새로 붙이지 않는다.

병사는 카드와 공통 이동·대형·포개기 변환을 따르고,카드 본체만 별도 commander-caption으로 들어올린다. 집단군 대표의 기존1.4배와 보조 카드 구성도 유지하되 같은 상단 배치를 따른다. 발밑에는 반투명 타원을 여러 겹 먼저 그려 부드러운 접지 그림자를 표시한다. 별도 SVG blur 필터/그림자 이미지를 해독하지 않는다.

전투 양측 간격은 커진 병사 대형의 폭을 고려한다. 싸움 아이콘의 여백을 유지하고 기존 영토·전투 표시점·엔진 위치·거리·피로·RNG를 변경하지 않는다. 왕 방어/고립지 철수/재등용·저장·선택 턴/배속·v0.50의 실제1.2초 전투 지역 강조는 그대로다.
