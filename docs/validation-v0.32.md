# v0.32.0 검증

- 기존 엔진/세계/저장/전투/재생/사운드 포함 43개 테스트 파일 통과. JavaScript 구문 검사 통과.
- 추가 standalone-pack 검사는 바이너리 전체 값의 인코딩 왕복, 단일 HTML 자동 실행, 내장 내용 보존, 외부 요청 없음과 실제 런타임 해제 코드를 Node VM에서 확인했습니다.
- 집단군 요약/상세 재생/16배속/국왕 선택 1배속/고배속 소리는 presentation-v32 및 audio-v24/playback 테스트로 확인했습니다.
- OFL Noto CJK KR에서 내장 글꼴을 재생성했습니다. 한글 11,172자와 선택된 KS X 1001 한자 및 라틴/일본어/기호 매핑을 보존했고 파일·라이선스 해시를 검사했습니다.
- 배포 HTML은 모든 그림·글꼴·효과음·코드를 포함하고, 열면 자체적으로 내용을 복원해 게임을 시작합니다. 사용자 파일 선택/설치/외부 CDN은 없습니다. 최신 Chrome/Edge/Safari의 DecompressionStream을 사용합니다.
- 브라우저 GUI/물리 스피커 청취 검증은 실행 환경의 Chromium 소켓 제한으로 수행하지 못했습니다.
