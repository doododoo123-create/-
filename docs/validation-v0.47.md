# v0.47.0 촬영 모드 검증

촬영 모드는 v0.46.1 게임 소스와 사용자 첨부 `장수70명_투명컷아웃_전투장식.zip`을 기준으로 추가했다. 엔진37과 세계/실행/역사 저장 형식은 변경하지 않았다. Android wrapper는 이번 변경 범위에 포함하지 않는다.

## 적용

- `filming-playback.js`: 기존 기록과 중간 프레임을 읽어서 촬영 장면을 구성한다. 결과 단계는 손실·승수·성장을 함께 표시하고, 영토/위치/생존 상태는 기록된 지도 공개 순서를 따른다. 공세를 전사·수도 함락 등에서 나누고 마지막에 전체 공세 결과를 제공한다.
- 연승은 불변 인물 ID로 실제 전투 승리를 세며, 패배/무승부에서 끊고 자동 점령을 제외한다. 망국 재등용 인물은 같은 신원으로 이어지고 후임은 새로 시작한다.5연승 이상과 교전 전3배 이상 상대 병력을 이긴 경우 결과 강조를 붙인다.3배 병력 차이 자체는 판정 보존 대상으로 삼아 강조가 승리를 미리 알리지 않도록 한다.
- 일반 전투 핵심 네 단계는1배속 기준2초, 사전 강조 전투는4초를 기준으로 한다. 이동·카메라·사망/멸망 공지는 별도다. 결과 확인 뒤 추가된 강조는 남은 결과/지도 구간을 늘린다. 높은 배속에는 읽기 최소 시간이 적용된다.
- `filming-view.js`와 `mobile-renderer.js`: 하단 정보와 인물 사진의 DOM을 유지하며 수치만 갱신한다. 이름은 현재 인물 상세를 연다. 전투 상세는 현재 공개된 전투 또는 완료된 공세만 보여준다.
- `filming-camera.js`: 화면 안전 영역을 기준으로 최소 이동하며 위치/줌은 화면 상태다. 카메라 전환 장면이 끝난 뒤 판정으로 진입하고 같은 재생 진행률로 이동/정지한다.
- 구간 재생/재촬영은 별도 재생 상태를 만들고 구간 끝에서 정지한다. 새 촬영 회차는 새 효과음 재생 기록을 사용한다. 구도는 세션 중 최대100개를 보관하며 앱을 다시 열면 초기화된다.
- 원본800×1200 RGBA WebP70장과 SVG2종은 원본 바이트를 유지했다. `scripts/filming-art.mjs`가 대응표를 검사해 내장하며 외부 이미지 요청을 만들지 않는다.

## 자동 검사

`tests/filming-v47.test.js`는 기록/세계/RNG 불변, 네 단계 시간, 결과와 소유권 분리, 인물별 연승과 후임/재등용, 공격/수비3배 승리·무승부·자동 점령 제외, 미래 점수/승리 배지 비공개, 전사 구간 분리, 재촬영 종료 및 효과음 상태 분리, 배속 변경 진행률, 국왕1배속 옵션, 안전 영역 카메라와 컷아웃/표시 설정을 검사한다.

`npm test`, `npm run check`, `npm run release`로 기존 검사와 단일 HTML을 확인한다. 실제160영토 기본 세계의3개 시드를 각각30턴 진행한90턴·206전투·4,606개 재생 단계에서 촬영 전후 전체 실행 기록 불변과 최종 표시 세계 일치를 확인했다. 빌드 후 압축 실행본을 풀어 JavaScript 구문과 외부 소스 참조도 검사한다.

## 최종 자동 검사 결과

2026-11-06 기준 `npm test`62개 테스트 파일 통과, `npm run check`303개 JavaScript 파일 구문 검사 통과, `npm run release` 성공. 배포 HTML은36,533,824바이트이며 원본 데이터70장 내장·JavaScript 구문·외부 실행 소스 참조 없음 검사를 통과했다.

## 브라우저 확인과 한계

오프라인 Chromium에서 실제7전투 기록을 불러와 촬영 진입, 상황 단계 점수/강조 비공개, 인물·사진 DOM 유지, 승패·손실 표시, 결과 정지,16배속 전투 재촬영의 구간 종료와 턴 유지까지 확인했다. 이 과정에서 공세 재촬영이 요약 직전에 멈추는 문제를 발견해 수정하고 자동 회귀 검사를 추가했다.

이후 브라우저 재실행은 실행 환경의 소켓 권한 제한으로 완료하지 못했다. 따라서 최종 수정 후 전체 공세/컷아웃/다중 해상도 브라우저 검증과 OBS 실제 녹화는 완료했다고 주장하지 않는다. 재현용 `tests/make-v47-fixtures.mjs`와 `tests/filming_v47_smoke.py`를 함께 제공한다. 실제 FPS·기기별 무지연을 측정하거나 보장하지 않는다.
