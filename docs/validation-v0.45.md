# v0.45.0 구현과 검증

기준은 Git 태그 v0.44.2이며, 일반판 HTML 하나를 갱신했다. 원본 지도·첨부 사진/소리 파일·v43 화면 재사용과 가벼운 배경·v44 카드1.4배·v44.1 수도 복귀 수정·v44.2 통일 공지를 보존한다.

## 구현

- 집단군 계산 후 기존 지도 장면을 먼저 재생한다. 실제 집결/진군, 전장 카드 포개기, 승패, 후퇴, 점령은 기록 순서대로 보인다. 공세 끝에 기존 표의 모든 행을 확정된 상태로 한 번 표시한다. 주사위 재회전·보정 비행·진행 행 점멸·별도 종합 상자는 없다. 기존 크기와 목록 스크롤을 유지하며 처음 교전부터 확인할 수 있다. 보고서의 전후 지도는 같은 최종 상태다. 일반1대1은 개별 주사위를 유지한다.
- 실제 사망(왕 포함)·임관·수도 함락·멸망 알림은 타이머와 효과/소리의 유효 배속을1로 한다. 일시정지와 사용자의 선택 배속은 수정하지 않으며 알림 이후 자동 복귀한다. 집단군 관련 실제 이동 duration은1.4배이고 CSS/지도/음향도 같은 시계를 사용한다. 다이스/룰렛·이동 거리/피로는 그대로다.
- 개인 무장 정수−4~+4는 역할별 성향 보정과 별개로 한 번 더한다. 기존 저자 능력을 존중하고 중립 장수는 이름/생애 기반 안정값을 배정한다. 편집/상세/전투 보정에 별도 표시하며 후임은 전임의 개인 편집값을 상속하지 않는다. 왕/승상 계산은 유지한다.
- 엔진35에서 새 차례 controls.personalAbility:true를 기록한다. 기존34 이하 controls 누락/false 전투는 당시 점수/RNG로 재구성한다. 기존 파일을 이어갈 수 있으며 완료된 전투·초기 세계를 덮어쓰지 않는다.
- 초상은 전 국가의 살아 있는 인물 전체에서 중복 없이 배정한다. 기존 생존자의 얼굴을 먼저 보존하고 멸망한 국가의 빈 사진도 사용한다. 사망자의 마지막 얼굴은 당시 프레임에 남긴다. 제공90장보다 많으면 이름 약자로 표시하고 빈 사진이 생기면 다시 사진을 배정한다. 표시용 portraitWorld 배정은 진행 파일/큰 저장소/역사에 보존하며 게임 난수를 쓰지 않는다.

## 자동 검사

- `npm test`: 561개 통과, 실패0. 새10개 검사는 실제4대4 공세의 지도 선행/확정표,1대1 유지,개인 점수 합계/왕 예외/기존34 재생/파일 왕복,중요 알림 타이머·효과1배속과 복귀,이동 시간1.4배,90개 사진 유일성/멸망 사진 재활용/후임·초상 부족 해소를 확인한다.
- `npm run check`: JavaScript285개 구문 검사 통과.
- `npm run release`: 실행용 단일 HTML 생성, 루트와dist 일치.
- 기존 멸망 시간 검사의 예전 기대값1500/1.2ms는 이번 승인된 실제1배속 알림의1600ms로 갱신했다. 기타 원본 대조/난수·과거 저장/규칙 검사를 유지했다.
