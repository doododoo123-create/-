# v0.51.1 작은 병사·촘촘한 대형

사용자 요청에 따라 병사 표시 크기를 기존의75%(54→40.5)로 줄이고,좌우 간격76→36~56(동작별)/앞뒤 간격72→48로 좁혔다. 병사 그림 수/개별 ID·종류·국가색·동작과 카드 정보·클릭을 보존한다. 카드 높이·발밑 그림자·부대 타원·전투 폭도 함께 조정했다.224픽셀 원본과 줌/DPR 재그리기는 유지한다.

## 확인

- 관련 화면/선택 턴 재생/카메라/병사 수 보존/대형 검사45개 통과.
- 원본42개 PNG의 모든 프레임 알파 범위를 양방향으로 측정했다. 현재 표시 크기에서 좌우 반전을 포함한 최대 폭54.603/높이42.127로56×48 간격 안에 들어간다. 서로 다른 동작/방향에서도 몸과 무기 원본 그림이 겹치지 않는 여유를 확보했다.
- JavaScript319개 구문 검사 통과,단일 일반HTML 생성 및루트/dist 바이트 일치.
- 엔진/저장 회귀16개 통과. 관련 검사 합계61개,실패0이다. 전체608개 검사는 이번 작은 화면 수정에서 다시 실행하지 않았다.
- 최종 일반HTML을 오프라인 Chromium1600×1000/DPR2에서 실행했다. 실제 기록 가져오기·병사 표시·카드 정보·일시정지 시 픽셀 유지·캔버스 CSS 크기×DPR·500% 확대/마우스 카드 상세·전투 지역 강조/시점 이동/고정1.2초를 통과했다. 앱 예외/요청 실패0이다. 시간은 가짜 시계로 확인했으며 FPS 측정이 아니다.
