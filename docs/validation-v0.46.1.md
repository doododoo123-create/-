# v0.46.1 집단군 집결 시점과 결성 확인

v0.46.0의 화면 연출만 수정한다. 엔진37·게임 난수·이동거리·피로·보급·전투 계산과 저장 형식은 그대로다. 고립지 충원 관련 추가 변경은 포함하지 않는다.

## 동작

- 시점 고정 상태에서 공격군과 수비군 모두 기록된 집결 영토를 계속 비춘다. 도착 순서에 따라 각 장수의 목적지를 따로 따라가지 않는다. 전원이 도착한 뒤 기존 결성 애니메이션을 유지한다.
- 결성 애니메이션이 끝난 완성된 집단군을 실제 재생 시간300ms 더 보여준다. 선택 배속0.5/1/2/4/8/16과 동작 줄이기의 영향을 받지 않는다. 일시정지 시 남은 시간을 보존한다.
- 이후 기존 진군 추적과 선택 배속으로 복귀한다. 시점 고정 해제 시 수동 시점을 유지하고 확대 배율도 바꾸지 않는다. 일반1대1에 결성 대기를 추가하지 않으며 결성음/확대 효과도 반복하지 않는다.
- 기존 경기 이어하기와 과거 역사 재생에서도 새 화면 흐름을 사용한다. 저장된 사건·초기 세계·위치·판정은 고치지 않는다.

## 검증

- `npm test`:580개 통과,실패0. 기존 전투·보급·저장/구형 역사·장기 진행 검사와 새 집결 시점/시간 검사를 포함한다.
- `tests/rally-camera.test.js`: 실제 공격/수비 집결과 구형 개별 도착 장면의 고정 시점,현재 배율·수동 시점·엔진 자료 보존,모든 배속/동작 줄이기의 정확한300ms,완성 카드·결성음 중복 방지,정지/배속 변경 후 남은 시간,1대1 대기 제외를 검사한다.
- `python tests/rally_camera_smoke.py`: 오프라인 Chromium1600×1000에서 실제 세계/시드로 재구성한 역사를 가져와1/16배속의 공격·수비 집결 시점 유지,완성 카드,300ms 뒤 진군 추적,일시정지/재개를 통과했다. 앱 예외/외부 요청 실패0. 가짜 시계로 타이머를 검증한 결과이며 FPS 측정은 아니다.
- `npm run check`: JavaScript294개 구문 검사 통과.
- `npm run release`: 일반 HTML 하나를 생성했다. 루트 실행본과dist 실행본은 동일하다.
