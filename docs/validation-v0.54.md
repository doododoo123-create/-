# v0.54 검증

임관 확정/재편/재등용 추적,소수전 단순화와 실행 중 전술 표시,교전 타격 표시,집결 확대 제거,전술창 화면 위치 고정,전투 후 점령/퇴각 지도 요약,장수별 병력 묶음과 카드 근접 배치를 적용했다.

엔진/저장/게임 난수는 수정하지 않았다. 지도 요약은 원래 기록의 실제 이동·점령 프레임을 사용하고 개인별 병사 그림 수를 유지한다. 최종 인물의 병력·생사를 사용하므로 사망이나 전투 손실을 다시 재생하지 않는다. 전투창은 계획별 위치를 보관하므로 DOM 갱신/배속/정지/지도 이동에도 고정된다.

기존 테스트에서1.4배 집단군 확대와 일반 주둔 카드 포개기를 요구하던 기대값은 이번 승인에 맞춰 고쳤다. 전투 카드 포개기 검사는 유지했다. 지도 결과 요약이 새로 생겨 관련 검사도 주사위/개별전 중복과 실제 점령/퇴각 재생을 구분하도록 갱신했다.

검증 항목: 확정 전 재등용이 확정 후 추적을 막지 않음,재편 임관 추적과 줌 유지,소수전/다대다 전술 수 제한,실행 시각과 참가 인물의 전술 알림,점령/퇴각 요약의 실제 기록 일치와 최종 상태,장수별 병력 묶음 분리,고정된 전투창의 DOM 갱신·팬 유지.

실행은 일반 단일HTML이다. 추가 이미지나 사운드 업로드는 필요 없다. 모든 기기의FPS는 측정하지 않았다.
