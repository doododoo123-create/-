## 배포와 범위

npm run release로 일반/경량 두 루트 실행본과 dist 파일을 동기화한다. 실행에 외부 이미지·CDN·계정이 필요 없다. JPEG90종을 포함해 이전 버전보다 파일 용량이 늘었다. 일반판과 경량판의 게임 결과는 같고 경량판은 지도 그림과 화면 처리만 줄인다.

클라우드 Chromium 관리 정책이 file://를 차단하므로 HTTP로 받은 단일 HTML의 오프라인 실행을 검증했다. 실제 Windows 더블클릭, Android/iPhone 실기기 성능은 이번 검증 범위 밖이다. 좁은 세로 화면에서 다수 카드가 겹칠 수 있으므로 지도 확대·이동/가로 화면을 사용할 수 있다.
