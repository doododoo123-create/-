## 실제 브라우저·오프라인 HTML

Chromium으로 일반판과 모바일 경량판 모두 외부 연결을 차단한 상태에서 실행했다.

- 신규160영토·시작 배치 유지·여섯 기능 기본 적용, 화면에서 혼란 최대치 변경/저장/기본값 적용.
- 실제 한 차례 진행 후 새로고침 복원, 왕의 독립 병력과 왕 상세의 경제/혼란 표시.
- 실제 왕 수비 주사위·혼란 보정 표시·붉은 전사 효과·자국3회 대기 후 새 왕의 별도 인물 ID·상세.
- 역사 클릭으로 왕 전투를 재생해도 현 경기 저장 내용은 동일하다.
- 전체화면 달력·배속 키·방향키,390×844/844×390 화면에서 달력이 화면 안에 표시된다.
- 이전26 실행을 연 뒤 편집 세계에만 새 규칙 적용: 진행 중인 경기 저장은 즉시 바뀌지 않으며,그 경기를 한 차례 더 진행해도 옛 체계/왕 예비병 구조를 유지한다.
- 확인 중 UI 예외와 실패한 외부 요청0. 실제 휴대전화 하드웨어의 프레임 속도/발열 측정이나 물리 스피커 청감 검사를 의미하지 않는다.

재현:

```sh
npm test
npm run check
npm run build
node tests/make-v27-fixture.mjs
python3 tests/studio_v27_smoke.py
```

브라우저 검사는`npm start`의3000포트,Python Playwright와Chromium이 필요하다. 일반 사용자의 HTML 실행에는 이 도구가 필요 없다. 캡처: [일반판 왕 방어](v27-normal-royal-defense.png),[왕 전사](v27-normal-royal-death.png),[모바일 세로](v27-mobile-390.png),[모바일 가로](v27-mobile-844.png). 작은 격자 지도는 전투 절차를 재현한 검사 시나리오이며 실제 신규 기본 지도는160영토다.

## 같은32개 시드의 장기 비교

두 설정 모두 승인된v25 시작160영토·국가 성향·인물·병력을 사용했다. 비교군은 새 여섯 스위치를 끈 기존26 규칙,실험군은v27 전체 적용이다. 시드는`777 + i×104729 (i=0..31)`. 플레이 자체는 제한 없음이며,측정만100계절 뒤 중단했다. 과거 답변의8시드 수치를 재사용한 결과가 아니다.

| 항목 | 기존26 규칙 | 새27 규칙 |
|---|---:|---:|
|100계절 내 통일|7/32|27/32|
|60계절 내 통일|1/32|10/32|
|전체 표본 통일 중앙값|100계절 초과|72계절|
|통일한 경기만의 중앙값|90계절|66계절|
|관찰된 통일 범위|52~94계절|40~87계절|
|적연국 승리|7|25|
|현해국 승리|0|1|
|청람국 승리|0|1|
|100계절에 미통일|25|5|

장기 정체는 줄었지만 **적연국 편중이 크다**. 현 배치·국가 성향·공세 빈도까지 포함한 표본이며,어느 한 규칙만의 효과를 분리한 실험이나 최종 밸런스 보증은 아니다. 이번에는 승인한 수치와 배치를 임의 변경하지 않았다. 후속 밸런스에서는 초기 국가 성향·영토·왕/장군 배치에 따른 승자 편중을 따로 비교할 필요가 있다.

원자료는[64회 결과 JSON](balance-v27-benchmark.json),재현은`node tests/benchmark-v27.mjs`. 생성 결과는`.artifacts/v27-benchmark.json`에 저장된다. 측정100계절이 앱의 턴 제한을 새로 만든 것은 아니다.
