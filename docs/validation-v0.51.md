# v0.51.0 원본 병사·고해상도 캔버스·개별 수 보존

사용자가 승인한 화질/가독성 수정과 병사 수 보존 정정을 적용한다. 같은 영토/실제 집단군 모두 각 장수의 기존1~3명 대표 병사를 더한다. 예:병사2+1+3명은6명이며 총병력으로 수를 다시 계산하지 않는다. 실제 지휘관별 군대·등급·전투/RNG·보급·저장/역사/배속은 유지한다.

## 구현

- PNG 원본은 보존하고 실행용 무손실 WebP도 원본1920×640을 사용한다.384×320 프레임/224 몸높이/피벗174,292로 잘라 그리며96픽셀 축소는 제거한다.
- 캔버스는 현재 CSS 표시 크기×모니터DPR로 만든다. 프레임 갱신 키에 크기를 포함해 정지 중 줌/화면 밀도 변경에도 원본 현재 프레임을 다시 그린다. 기존 병사 화면 크기와75% 정보 카드를 유지한다.
- 전체 실루엣 바깥의 흰 윤곽,얕은 어두운 그림자,발밑 그림자,국가색 타원을 표시한다. 실제 현재 교전자의 윤곽/표식을 강화한다. 바로 주변의 겹치는 지명/지난 경로만 약하게 하며 전투 지역명과 화면의 전투 참여자 경로는 유지한다. 전투가 끝나면 복원한다.
- 같은 국가/영토/진영의 정지 부대는 하나의 표시 대형에서 개별 병사를 그린다. 이동 중 개인은 분리하고 대표/보조 장수를 중복 합산하지 않는다. 개별 ID/등급/행동을 병사마다 보존한다. 카드 포개기의 전면이 바뀌어도 공통 병사 대형을 수평으로 밀지 않도록 포개기 이동을 상쇄한다.
- 원본 전신/무기를 포함한 모든 포즈의 실루엣 범위를 고려한76×72격자로 배치한다. 인원이 많으면 줄을 늘리며 그림 수를 잘라내지 않는다. 카드도 대형 높이에 맞춰 위로 배치한다.

## 메모리·성능 범위

원본 동작자료6쌍을 공유하고,국가색 프레임 캐시48MiB와 흰 실루엣24프레임을 사용한다. 원본 이미지를 지휘관마다 복제하지 않는다. 실제 사용 중 이미지 참조/비동기 해독/화면 캔버스가 추가되므로 이 값은 전체 앱 메모리 상한이 아니다. 화면 밖은 그리기를 쉬고 윤곽에 매번 필터를 적용하지 않는다. 측정하지 않은 FPS/무지연을 보장하지 않는다. 원본보다 크게 확대하면 원본 해상도 자체의 한계는 남는다.
