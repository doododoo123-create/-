# v0.45.1 해상 보급 중단

앞서 승인된 해상 보급 중단을 반영했다. 새 편집 세계는 육지 보급이며 기존 경기는 다음 새 차례부터 `controls.landSupplyOnly:true`를 기록해 육지 보급을 지속한다. 과거 완료 기록/초기 세계는 당시 해상 연결/RNG를 그대로 재생한다. 엔진36은35 이하를 읽는다.

이번 변경은 국가 전체 유지 한도5만×영토 수·계절 초과분25% 탈영을 유지한다. 추가로 요청한 고립 보급권별 유지 한도는 검토 단계이며 구현하지 않았다. 판정표 고정1초와 망국 장수 본인의 재등용도 이 패치에 포함하지 않았다.
