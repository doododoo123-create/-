# v0.56.2 지역별 기록 전투

기준은 v0.56.1 태그 ef5f1146abf78a818c73bc4ed0c5fd36bf34ac9c이다. 이후 버전의 기능은 가져오지 않았다.

- 14전술 선택과 자유 연출 대신 같은 전선·지역·공격 방향의 연속 기록으로 지역 방문 구간을 만든다. 같은 지역 재공격, 역공, 다른 전선은 별도 구간이다.
- A의8대결을4대5 집단전으로, 다음 B의1대결을1대1로, C의무방비 기록을 진입으로 표현한다. 지역별 시작 병력과 실제 참가자를 이어받으며 한 장수는 하나의 병사 묶음만 갖는다.
- 이름/병력/생사/후퇴·철수/재편과 지역 소유는 기록된 중간 프레임에서 읽는다. 자동 점령이 여러 칸이면 기록된 순서로 각 지역에 진입한다. 결과를 전술창에서 보여준 뒤 지도에는 최종 상태를 한 번 넘긴다.
- 지역 소유국/현재 위치/부대 수를 상단에 표시하고 현재 전장을 강조한다. 국가색은 역공에서도 유지하고 공격·방어 역할만 바뀐다. 패배와 전사는 구분하며 대기 부대에 교전 모션/피해를 만들지 않는다.
- 기존 전장 대치·아이콘 기준 진입과 고정 창 위치, 배속/일시정지/선택 턴 촬영/상세 기록/다시 보기/건너뛰기를 유지한다. 중요 사건1배속·요약1초 보호와 기존 음원 재생기를 쓴다. 게임 엔진/RNG/규칙/저장 파일은 변경하지 않았다.
