# Studio v0.1 임시 규칙

이 규칙은 세계 편집·저장·자동 실행을 연결하기 위한 최소 규칙이다. 첨부 룰북 v11 전체를 구현한 것으로 해석하지 않는다. 원본 규칙은 `reference/legacy-rulebook-v11.md`에 보존한다.

## 기본 설정

| 항목 | 기본값 | 화면 편집 |
|---|---|---|
| 주사위 | D10, 1~10 균등 | 2~100면 |
| 국왕/국가 균형형 내정 | 1~5, 나머지 전쟁 | 0~주사위 면 수 |
| 내정형 내정 | 1~7 | 동일 |
| 호전형 내정 | 1~3 | 동일 |
| 내정 성공 | 주사위+승상 능력 ≥6 | 성공 기준과 인물 능력 |
| 내정 행동 선택 | 모병/충원 강화 각 50% | 이번 버전은 비율 편집 없음 |
| 모병 성공 | 즉시 +3만 명 | 0~10,000만 |
| 충원 강화 성공 | 라운드당 추가 충원 영구 +3만 | 동일 |
| 라운드 생산 | 영토 수×1만+국가 추가 충원 | 영토당 생산과 국가 충원 |
| 전투 병력 우세 | 많은 쪽에만 +1점 | 0~10 |
| 승/무/패 손실 기본률 | 30% / 40% / 50% | 각 0~100% |
| 점령 | 공격 승리 시 1영토 | 현재 고정 |
| 제한 | 30라운드 | 1~1,000 |

0 내정 구간은 항상 전쟁을, 주사위 면 수와 같은 구간은 항상 내정을 시도한다. 공격할 수 없는 경우에는 내정으로 전환한다. 주사위 각 면은 균등하며 임의의 비균등 확률표 편집은 후속 기능이다.

## 행동 순서

국가 목록 순서대로 영토를 가진 나라만 참여한다. 각 라운드 시작에 참여 순서를 만들고, 멸망한 국가는 이후 순서에서 건너뛴다. 국왕이 있으면 국왕 성향, 없으면 국가 기본 성향으로 행동을 정한다. 국왕·승상이 없는 나라와 장군이 없는 나라도 실행할 수 있다.

병력이 0이거나 인접한 타국 영토/무주지가 없는데 전쟁이 나오면 내정으로 전환한다. 원본의 재추첨 대신 한 번의 전환으로 처리한다. 내정은 모병과 충원 강화 중 하나를 50%씩 선택하고, 새 주사위에 승상 능력(없으면 0)을 더해 성공을 정한다. 능력 보정 후 점수는 주사위 범위로 잘라내지 않는다. 내정 선택용 균등 추첨은 기록의 `action`으로 남고 표시 주사위는 아니다.

국왕의 능력 수치, 승상과 장군의 성향은 현재 판정에는 사용하지 않는다. 장군 여러 명 중 가장 높은 능력을 쓰며 동률이면 등록 순서의 첫 사람을 사용한다.

## 전쟁

자국 영토와 상하좌우로 맞닿은 타국 영토 또는 무주지를 후보로 한다. 대각선은 인접하지 않는다. 후보 영토를 균등 추첨한다. 자국 연결 영역/주둔지별 범위 제한은 아직 없다.

한 국가의 전쟁은 한 번의 전투이며, 병력은 장군별 부대가 아닌 국가 전체를 사용한다.

`공격/방어 점수 = 각자 D면 주사위 + 대표 장군 능력(없으면 0) + 병력 우세 보정`

공격 점수가 더 높으면 해당 영토 1개를 점령한다. 방어 승리나 동점에서는 영토가 그대로다. 반격 점령은 없다. 무주지 또는 국가 병력이 0인 상대의 영토는 전투 주사위/손실 없이 1개 점령한다. 대상 선택은 균등 난수이며 선택된 영토와 전투 수치는 기록에 남긴다.

## 손실

양측 전투 시작 병력으로 동시에 계산한다.

`손실 = 내 병력 × 내 결과의 기본률 × (적 병력 × 2) ÷ 양측 시작 병력 합`

정수 반올림하고 자기 병력을 넘지 않는다. 해당 기본률이 0이면 손실도 0이다. 그렇지 않으면 최소 1만 명을 잃는다. 병력 0은 멸망이 아니다. 영토를 가지고 있으면 이후 내정·라운드 생산으로 다시 충원한다. 이 버전에는 장군 전사나 후임이 없다.

## 라운드 종료와 승리

이번 라운드 모든 생존국이 행동하면 생존국 전체에 생산량을 더한다. 영토 0인 나라는 생산하지 않으며 멸망 순간 남은 병력도 제거한다. 시작부터 영토가 없는 국가는 참가하지 않고 실행 복사본의 병력을 0으로 둔다. 편집 세계의 초기 병력은 보존한다.

경쟁 국가가 하나 남으면 조기 종료한다. 무주지가 남아 있어도 경쟁자가 없으면 종료한다. 라운드 도중 종료라면 즉시 결과를 내며, 마지막 예정 행동에서 끝난 경우에는 라운드 생산 후 결과를 낸다. 제한 라운드 종료는 생산을 마친 뒤 영토 수 → 병력 순으로 승자를 정하고 모두 동률이면 공동 승리다.

## 원본 v11과의 차이

원본의 장군별 병력·수도방위군·지휘한도·구역 재편·고립 보급·후임·연결 우선 목표·1~3개 점령은 이번 Studio 엔진에 없다. 승상 성향에 따른 3종 내정과 보급 강화도 없다. 따라서 같은 이름과 시드라도 원본 HTML과 Studio의 결과는 서로 다르다. 기존 원본 HTML은 독립 링크에서 그대로 실행할 수 있다.

## 재현 조건

세계 JSON의 국가·인물 순서와 영토 좌표 정렬, 규칙, 시드 문자열과 `studio-0.1` 엔진 버전이 같아야 한다. 같은 세계에 다른 성향/병력/인물을 저장하면 다른 입력이다. 시드는 실제 판정용이며 배속·화면 이동·표시 설정이 결과에 영향을 주지 않는다. 기록을 화면에서 재생하거나 중간부터 재개하는 기능은 아직 없다.
