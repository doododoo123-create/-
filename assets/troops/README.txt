사국쟁패 병력 3티어 애니메이션 통합본

1티어: 평상복·두건·외날 도의 농민병
2티어: 기존 정규 창병
3티어: 도·대형 방패의 정예 중보병 (기병 아님)
각 7동작 × 10프레임 = 총 21동작·210프레임

먼저 압축을 모두 풀어 주세요. HTML만 압축 안에서 열면 옆 자료를 찾을 수 없습니다.
01-animations.html을 크롬으로 열면 세 티어 동시 비교, 선택 티어 확대, 나라색, 좌우 반전, 프레임 정지, PNG와 전체 시트 ZIP 내보내기를 사용할 수 있습니다.
02-map.html은 50번 지도에서 병력 외형을 비교하는 예시입니다. 실제 전투 판정이나 저장 데이터와 연결하지 않았습니다.

assets/: 티어별 body(나라색 부분 투명), shade(옷 명암), mask(나라색 영역)와 위치 자료
colored/: 기본 적연국 색상의 티어별 7개 완성 시트
renderer.js: 전신 프레임 재생·국가색 합성·캐시
tier-bank.js: 필요한 동작 자료를 읽는 도우미
troops-data.js: 오프라인에서도 그림의 색을 바꿀 수 있는 내장 그림 자료
frames.json: 모든 동작 위치와 시간 정보
generation-prompts.json: 새 1·3티어의 생성 지시문
tier2-generation-prompts.json: 기존 2티어 생성 지시문

색칠 위치: 1티어 두건·허리띠 / 2티어 옷·장식 / 3티어 옷·장식·방패 띠. 같은 나라색을 사용합니다.
대기는 하나의 정렬한 전신 기준 자세에 작은 호흡 변형을 적용했습니다. 나머지 동작은 전신 포즈 프레임입니다. 프레임 사이의 크로스페이드는 사용하지 않습니다.
공격·방어·피격은 1회, 대기·행군·후퇴는 반복합니다. 사망은 동작 뒤 450ms 유지하고 350ms 동안 사라집니다.
원본 50번 게임의 규칙·판정·저장 데이터는 수정하지 않았습니다.
