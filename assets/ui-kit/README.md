# 칠목과 청동 UI 자원

사용자가 제공한 `사국쟁패_UI이미지_77종.zip`에서 가져온 77개 디자인입니다. 동일 그림의 PNG/SVG 중 SVG를 보관하고, 큰 아트 8개는 비율과 투명도를 유지해 배포용 WebP로 축소·압축했습니다. 원본 안내는 SOURCE-NOTES.md에 보관했습니다.

- 01-art: 바탕·지도/인물 프레임·명령 패널·종이·현판·전투 배너·주홍 버튼 8종.
- 02-controls: 4색 × 기본/호버/눌림/비활성 16종. 화면에서는 border-image로 모서리를 보존합니다.
- 03-icons: 29개. 빌드가 scripts/ui-kit.mjs를 통해 정적인 인라인 경로로 변환합니다. 원본 SVG를 바꾸고 빌드하면 반영됩니다.
- 04-dice: 11개. 실행 화면은 빈 프레임에 실제 숫자를 겹칩니다. 높은 숫자의 붉은 색, 10 초과 보정값을 보존합니다.
- 05-markers: 9개. 국가 깃발의 모양과 장군 프레임을 사용하고 색은 실제 국가 설정을 따릅니다.
- 06-meters: 4개. 영토 현황 게이지의 바탕에 적용합니다.

표시 스타일은 src/ui/lacquer-bronze.css에 분리했습니다. 실행에 필요한 자원은 build/release에서 CSS data URL과 인라인 아이콘으로 단일 HTML에 들어갑니다. SVG 원본에는 스크립트·외부 이미지·외부 링크를 넣지 마세요.
