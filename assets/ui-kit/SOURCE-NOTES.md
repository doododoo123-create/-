# 사국쟁패 UI Kit — 칠목과 청동

첨부된 사국쟁패 Studio HTML의 세계 편집·국가·인물·지도·주사위 전투·턴 재생 기능에 맞춘 UI 이미지 모음. 고유 디자인 77종. 보조 디자인은 동일 그림의 PNG와 SVG를 함께 제공하며 별도 디자인으로 중복 계산하지 않았습니다.

## 열어보기
압축을 풀고 preview.html을 브라우저로 열면 모든 리소스를 확인할 수 있습니다.

## 폴더
- 01-art: 이미지 생성으로 제작한 주요 아트 8종. 패널·지도 프레임·인물 프레임·주홍 버튼·전투 배너·현판·먹빛 배경.
- 02-controls: 4색 명령 버튼 × 기본/마우스오버/눌림/비활성 상태 = 16종.
- 03-icons: 세계·지도·국왕·승상·장군·병력·충원·공격·방어·수도·영토·내정·연대기·주사위·보정·연결·단절·재생·정지·단계 진행·결과·저장·불러오기·편집·설정·닫기·뒤로·추가 등 29종.
- 04-dice: 대기 프레임과 1~10 숫자 타일 11종. 실제 판정 주사위의 범위에 필요한 값만 사용. 보정 후 최종 값이 10을 넘을 수 있으므로 실제 게임에서는 die_empty 위에 동적 숫자를 표시하는 방식 권장.
- 05-markers: 국가색 깃발 7종, 장군 원형 프레임, 수도 표식 9종.
- 06-meters: 진행도 홈과 병력/내정/시간 채움 4종.

## 이미지 적용
1. 우선 적용할 곳은 지도 프레임 → 주요 명령 버튼 → 장군 카드 → 주사위 영역 → 제목 현판 순서.
2. 장식은 중요 영역에만 배치. 작은 정보카드마다 무거운 아트 테두리를 반복하지 않기.
3. 판독성이 중요한 숫자·국가명·장군명은 실제 HTML 텍스트 유지. 글자가 포함된 이미지는 주사위 숫자 타일뿐.
4. frame_map / frame_portrait는 중앙 창이 투명. 지도·초상화 위에 겹치기. 프레임 바깥에도 부드러운 그림자가 있으므로 가장자리 5~10% 여유 유지.
5. 주요 아트는 그림 안에 투명 여백이 존재. 게임 요소의 클릭 영역은 실제 버튼 박스에 맞추고 이미지는 장식 레이어로 배치.
6. 주요 프레임·패널은 원래 비율 유지. 아무 비율로나 늘리면 청동 문양이 찌그러짐. 가변 크기 목록·버튼에는 SVG 보조 리소스나 단순 CSS 선을 사용.
7. 버튼의 안전 텍스트 여백은 좌우 42px, 상하 20px (384×96 원본 기준). 축소 후 최소 높이 44px 권장.
8. 아이콘은 원본 128×128 PNG, 화면에서는 24~32px로 사용. 색상은 SVG currentColor 또는 stroke 값을 수정.
9. 게이지는 홈 안쪽에 채움을 놓고 부모 overflow:hidden 영역 너비를 비율에 따라 변경. 채움 전체를 늘리기보다 마스킹해서 양끝 형태 유지.
10. integration.css는 첨부 게임의 .button 등과 연결하는 선택적 예시. 게임 HTML은 이 모음집에서 수정하지 않았음.

## 제작
주요 아트 8종은 내장 이미지 생성 도구로 제작. 작은 UI 심볼·상태 버튼은 직접 작성한 SVG를 PNG로 출력. 생성 지시문은 generation-prompts.txt에 포함.
