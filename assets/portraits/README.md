# 장수 초상화 50종

사용자가 제공한 장수_초상화_50명_경량.zip에서 가져왔습니다. JPG 384×576 원본을 비율을 유지한 WebP 288×432로 배포용 압축했습니다. 원본 설명은 SOURCE-NOTES.txt에 보관하며 능력·성향 규칙으로 사용하지 않습니다.

scripts/general-portraits.mjs가 빌드 때 general_001.webp~general_050.webp를 src/data/general-portraits.js에 동기화합니다. 세계에는 general-001~general-050 선택 키만 저장합니다. 자동 배정은 인물 ID에 따라 안정적으로 정하고 게임 난수를 소비하지 않습니다. 얼굴 확대는 src/ui/map-refinements.css의 표시 설정입니다.

50은 내장 사진의 수이며 국가나 인물 수의 제한이 아닙니다. 같은 사진을 여러 인물이 사용할 수도 있습니다.
