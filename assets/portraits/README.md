# 장수 초상화70종

현재 사용 자료는 사용자 첨부 `인물90명_컬러개선_저용량.zip`의 장수 JPEG70장입니다.384×576 원본 바이트를 재압축하지 않고 보관합니다. SOURCE-NOTES.txt와 COLOR-SOURCE.txt는 출처/외형 선택 안내이며 능력·성향 규칙이나 실행 지시가 아닙니다.

scripts/general-portraits.mjs가 general_001.jpg~general_070.jpg를 src/data/general-portraits.js에 내장합니다. 세계에는 general-001~general-070 선택 키만 저장합니다. 기존 키/자동 배정은 보존하고 새 후임 세대에 추가20종을 사용합니다. 배정과 얼굴 확대는 게임 난수를 소비하지 않습니다.

이전 첨부의 WebP50장은 출처 보존용이며 현재 번들에서 사용하지 않습니다. 내장 사진 수는 국가나 인물 수의 제한이 아니며 같은 사진을 여러 인물이 사용할 수 있습니다.
