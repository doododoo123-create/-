# 코덱스 전달용 지도 적용 안내

## 적용 요청

기존 게임의 지도를 동봉한 최신 삼국지풍 160영지 지도로 교체해 주세요.
기존 턴·전투·국가·장수·병력·저장 기능과 게임 UI를 유지하고, 새 지도의 영지 선택·확대·이동을 연결해 주세요.
기존 게임 코드가 있는 저장소/프로젝트에서 작업하는 것을 전제로 합니다. 이 묶음 자체는 게임 전체가 아니라 지도 모듈입니다.

## 파일 4개

- `continent_160.html`: 최종 지도 원본. SVG, 이미지, 질감, 스타일, 메타데이터와 지도 엔진이 모두 내장되어 있습니다. 브라우저에서 단독 확인할 수 있습니다.
- `map-engine.js`: HTML에 내장된 지도 제어 코드를 따로 추출한 동일한 파일입니다. 연동 검토·수정용이며 원본 HTML과 함께 두 번 실행하면 안 됩니다.
- `map-data.json`: HTML의 `#map-data`에 있는 동일한 지도 메타데이터입니다. 160개 영지 ID, 중심점, 경계 상자, 인접 관계, 지형, 정착지 정보를 확인할 수 있습니다.
- `CODEX_HANDOFF.md`: 이 설명서.

별도 이미지 다운로드, 추가 SVG, 미리보기, 이전 버전이나 전체 제작 소스는 기본 지도 교체에 필요하지 않습니다.

## 먼저 확인할 사항

- 버전 2.3.0, 지도 좌표계 `0 0 1800 1060`, 확대 100~500%입니다.
- 영지 ID는 `territory-001`~`territory-160`입니다. HTML의 `.territory` 경로와 JSON의 같은 ID를 연결합니다.
- 기존 게임의 영지 개수·ID·인접 관계를 먼저 비교하세요. 개수가 같다는 이유로 배열 순서만으로 연결하지 마세요. 기존 국가·주둔지·수도·공격 대상·세이브에서 사용하는 영지 ID와 명시적으로 매핑해야 합니다.
- 기존 게임이 80영지 등 다른 구성을 사용하면 그림 교체만으로 호환되지 않습니다. 160영지 데이터로 전환할 범위와 기존 세이브의 처리 방식을 먼저 정리해 주세요.
- 이 지도는 완전 벡터 삽화가 아닙니다. 클릭 영역·영지 경계·필지·외곽 마감은 SVG이며, 건물·산·숲·지면은 500% 확대에 맞춘 이미지를 내장합니다.

## 통합 방법

1. 먼저 작은 `map-engine.js`와 `map-data.json`을 읽으세요. HTML은 이미지 때문에 약 38.2MB이므로 전체 내용을 모델 입력이나 터미널에 출력하지 말고 DOM/XML 도구로 필요한 노드만 추출하세요.
2. 기존 게임 HTML 전체를 이 파일로 덮어쓰지 마세요. 지도 영역에 원본의 `svg#atlas`를 이식하거나 기존 앱 구조에 맞는 지도 컴포넌트로 옮기세요. 상단 도구 모음·사이드바는 지도 확인용 화면이므로 기존 게임 UI에 맞춰 처리합니다.
3. `svg#atlas`의 `defs`, 스타일, 그리기 레이어, `#map-data`, `#texture-assets` 및 이미지 참조를 함께 유지하세요. 질감 셀과 관련 필터를 임의로 누락하면 화면 품질이 달라집니다.
4. SVG가 DOM에 붙은 다음 지도 엔진을 한 번만 초기화합니다. 현재 엔진은 `window.ContinentMap`을 제공합니다. SPA라면 재마운트 전에 기존 인스턴스의 `destroy()`를 호출하고 초기화 흐름을 맞추세요.
5. 영지 선택 이벤트를 게임의 선택·이동·공격 처리로 연결하세요. 기존 UI의 확대·이동 제어가 있다면 중복 입력 처리를 정리하세요.
6. 이식한 인라인 SVG에서 영지 클릭과 게임 오버레이를 연결하세요. 단순히 `<img src="...">`로 넣으면 내부 경로와 지도 API를 직접 다룰 수 없습니다.

## 실제 제공 API

```js
const map = window.ContinentMap;
const territories = map.getTerritories();
const territory = map.getTerritory('territory-001');
const unsubscribe = map.on('select', ({ id, territory }) => {
  if (!id) return;
  // id를 기존 게임의 영지 ID에 매핑하고 게임 선택 로직 호출
});
map.select('territory-001');
map.focus('territory-001', 3);
map.zoomTo(5); // 500%
map.fit();
```

- `getTerritory(id)`: 영지의 `center`, `neighbors`, `bounds`, `terrain`과 현재 `state` 등을 반환합니다. 원본 벡터 경로는 HTML에 있습니다.
- `setTerritoryState(id, patch)`: 지도에 연결된 상태를 갱신합니다. 소유국·병력 필드를 넣었다고 국가 색이나 병력 표지가 자동 생성되는 기능은 아닙니다. 기존 게임의 표시 로직을 연결해야 합니다. 병력 단위도 기존 게임 기준으로 맞추세요.
- `getLayers()` / `setLayer(name, visible)`: 레이어 목록 조회와 표시 전환입니다. `cultivation`은 논밭 외곽 마감도 함께 제어합니다.
- `exportState()` / `importState(state)`: 지도 상태용입니다. 게임 전체 저장 기능을 대신하지 않습니다. 다른 지도 ID의 저장 상태는 그대로 가져올 수 없습니다.
- `texturesReady()`: 현재 화면에 필요한 질감 로딩 완료를 기다립니다.
- `exportSVG({currentView: true})`: 내장 질감을 포함하는 SVG를 내보냅니다.
- `destroy()`: 이벤트와 질감 자원을 정리합니다.

## 유지할 시각적 결과와 확인

- 풍부한 바닥 질감, 진한 논밭, 불규칙한 작물 끝, 낮은 흙둑·풀 가장자리, 북쪽 빛에 따른 남쪽 그림자를 유지합니다.
- 해안·하천·대로·160개 영지 경로를 장식 때문에 변경하지 않습니다. 농로나 좁은 샛길은 추가하지 않습니다.
- 지도 원본과 비교해 동일한 구역을 100%·500%에서 확인하세요. 클릭·드래그·확대·영지 중심 좌표와 공격 화살표가 일치하는지, 국가별 소유권·인접 공격·세이브가 기존 게임과 연동되는지 검증하세요.
