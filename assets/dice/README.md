# 제공 주사위 1~60

사용자가 제공한 `사국쟁패_다이스_1-60.zip`의 `다이스_1-60/die_01.svg`~`die_60.svg`를 변경 없이 보관합니다. 확대 시 선명한 SVG를 사용하며 함께 제공된 PNG는 중복 내장하지 않습니다.

`scripts/studio-art.mjs`가 빌드 때 `src/data/studio-art.js`로 동기화합니다. 화면에서 SVG의 그라데이션 ID를 인스턴스별로 구분하고, 실제 숫자에 따라 글자를 흰색~빨강으로 표시합니다. 기본 전투는 D30, 내정은 D10입니다. 규칙에서 전투 눈금을 최대 60까지 설정할 수 있습니다. 최종 보정값이 60 초과 또는 1 미만이면 빈 앞면 위에 실제 숫자를 표시합니다.

굴림 중에는 고정된 장식용 앞면들을 교체합니다. 엔진 주사위를 다시 뽑거나 확정될 실제 눈금을 미리 노출하지 않습니다.
