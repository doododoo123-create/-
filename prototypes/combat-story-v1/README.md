# 전투 흐름 검증용 프로토타입

정식 게임과 분리된 단일 HTML 시연입니다. HTML을 우클릭하여 저장한 뒤 Chrome/Edge에서 열고 재생하세요. 일시정지, 1/2/4배속, 시간 이동, 주요 구간 선택을 지원합니다.

현재 게임 엔진으로 계산한 시드777/고정 주사위 시험 기록 한 개를 사용합니다. A지역 4대5(공격3부대 패배 뒤 공격4가5부대를 이김), B지역1대1, C지역무방비 진입을 재생합니다. 병력과 승패는 기록에서 읽으며 화면의 좌표와 시간은 이 시연에 맞게 구성했습니다.

브라우저에서 모든 판정 후 병력/생사, 장수 중복 없음, B진입15만/C진입14만, 마지막 병력, 되감기 결정성, 정지/재개/배속을 검사했습니다. 녹화는 실행 브라우저의 실제 화면이며 생성 영상이 아닙니다.

이 시안은 한 시험 경기용입니다. 모든 세계/대규모 전투/전사/역공/저장·역사 재생과의 통합은 구현 또는 검증하지 않았습니다. 원래 게임의 source/HTML과 v0.56.4는 변경하지 않습니다.
