사국쟁패 Studio v0.4.0 · 자유 대륙과 지휘관 이동

1. 실행용 HTML을 받으세요. ZIP으로 받았다면 먼저 압축을 풀어 주세요.
2. 사국쟁패 Studio.html을 Chrome 또는 Edge로 여세요.
3. 시뮬레이션 → 한 턴 진행을 누르면 시작합니다.
4. Space: 다음 판정 묶음 / Enter: 남은 한 턴 / 자동 진행: 연속 실행·정지.
5. 완료된 턴은 자동 저장하고 새로고침 뒤 이어서 진행합니다.
6. 중요한 세계와 역사는 파일 내보내기 / 기록 내보내기로 별도 보관하세요.

첨부 룰북 v11과 HTML의 장군별 병력·주둔지·생산·보급·전투·전사·후임 시스템을 사용합니다.
원본과 같은 초기 세계·기본 규칙·숫자 시드는 같은 계산 결과를 냅니다.
지도 국왕 숫자: 수도 예비병 / 장군 숫자: 각 부대 병력 / 국가 카드: 총병력.
지도 전체화면에서는 지도만 보이고 판정할 때만 인물·주사위·특성이 중앙에 나타납니다.
전투는 공격 장군 + 주사위 VS 수비 장군 + 주사위 형태입니다.
중앙 창이 사라진 뒤 부대·수도에 +/− 병력, 영토에 점령, 강화에는 충원력/지휘한도 변화를 표시합니다.
Space: 판정 묶음 / Enter: 남은 한 턴 / A: 자동 진행·정지 / S: 턴 결과 / Esc: 전체화면 닫기.
배속은 일반 화면에서 설정한 뒤 전체화면에 들어가세요.
주사위 숫자가 높을수록 점점 빨갛게 표시됩니다.

처음 예제로 복원: examples 폴더의 세계 JSON을 앱에서 불러오세요.
이전 Studio 세계도 불러올 수 있으며 편집 내용을 보존하고 v11 규칙으로 전환합니다.
기존 단순 엔진의 진행 기록은 v11 경기로 변환하지 않습니다.

소스코드: src / 원본 HTML·룰북: docs/reference / 테스트 결과: docs/validation.md

지도 · 영토에서 새 지도 편집기를 사용할 수 있습니다.
- 배경 이미지 불러오기: 내 지도 그림을 저장합니다. 국경 자동 추출은 하지 않습니다.
- 경계 꼭짓점 이동 / 경계 다시 그리기 → 경계 적용으로 저장합니다.
- 이름·부대 위치 / 인접 관계 / 소유권 칠하기 / 색 진하기 / 확대를 조절합니다.
- 인접 관계에서 다른 영토를 누르면 연결·해제합니다. 실제 공격과 보급은 이 연결을 사용합니다.
- 편집 되돌리기는 최근 12번의 지도 편집을 복원합니다. 국가·인물 수정 후에는 되돌리기 기록을 새로 시작합니다. Esc는 작성 중 경계를 취소합니다.
- 파일 내보내기에 그림·경계·연결도 함께 저장됩니다. 수정은 새 실행부터 적용됩니다.
- 기존 기본 지도와 격자 편집 화면도 선택할 수 있습니다.

새 UI: 제공한 이미지 모음집의 먹빛 바탕·청동 지도/인물 프레임·주홍/옥색 버튼·육각 주사위·종이 기록을 적용했습니다.
숫자·인물 이름은 실제 데이터로 표시하고, 기존 저장과 시뮬레이션 규칙은 유지합니다.
이미지를 HTML 안에 넣었으므로 이미지 폴더를 따로 받을 필요가 없습니다.

이번 수정:
- 장수 초상화 50종을 내장했습니다. 인물 관리에서 직접 고를 수 있습니다.
- 지도 카드는 확대된 얼굴 → 이름 → 병력 순서의 작은 세로 형태입니다.
- 이름 뒤에 붙던 3대1·1대1 같은 후임 구분 표시는 화면에서 숨깁니다.
- 공격/수비 화살표와 전투 표식을 정리하고 중앙 주사위를 위로 올렸습니다.
- 기본 지도의 바다에 자연스러운 물결과 해안 수심 색을 적용했습니다.

이번 버전은 참고 그림 기반의 새 자유 대륙과 삽화형 바다입니다.
기존 저장 지도가 나오면 지도 · 영토 → 참고 대륙 적용(80영토 세계)을 누르세요.
영토 추가: ＋ 영토 그리기 → 점 3개 이상 → 경계 적용.
영토 선택 후 영토 통째로 이동 / 영토 삭제를 사용할 수 있습니다.
맞닿은 경계로 연결하거나 인접 관계에서 직접 연결하세요. 지도와 연결은 별도로 편집합니다.
공격 장군은 자국 전선 근처로 출정하고 담당 지역이 공격받으면 복귀합니다.
이동은 화면 연출이며 원본 전투와 보급 계산을 바꾸지 않습니다.
